🎟️ QuizWitz PRO - Πώς λειτουργούν τα Seats

Τα παιχνίδια QuizWitz PRO απαιτούν ενεργά Seats για τη σύνδεση των παικτών. Τα Seats είναι ένα ευέλικτο σύστημα, pay-as-you-go ή με άδεια χρήσης, που προσαρμόζεται στις ανάγκες σου - ιδανικό για pub quiz, ζωντανές μεταδόσεις και επαγγελματικές εκδηλώσεις κουίζ.

🧑‍🤝‍🧑 Τι είναι τα Seats;​

  • Κάθε συνδεδεμένος παίκτης ή ομάδα σε ένα παιχνίδι PRO απαιτεί 1 ενεργό Seat.
  • Μπορείς να φιλοξενείς παιχνίδια με μεμονωμένους παίκτες ή ομάδες που μοιράζονται μία συσκευή - καθένα μετρά ως ένα Seat.
  • Τα παιχνίδια σε λειτουργία Παιχνίδι παρέας και Ένας παίκτης δεν απαιτούν Seats και είναι ιδανικά για χαλαρό παιχνίδι με φίλους ή οικογένεια.

🎮 Δωρεάν Seats για όλους​

  • Κάθε λογαριασμός περιλαμβάνει 3 δωρεάν Seats ανά παιχνίδι, διαθέσιμα σε όλους τους χρήστες, ακόμη και χωρίς άδεια χρήσης PRO.
  • Αυτά τα Seats σου επιτρέπουν να φιλοξενείς μικρά κουίζ με φίλους ή να δοκιμάζεις το περιεχόμενό σου χωρίς κόστος.
  • Τα 3 δωρεάν Seats δεν μετρούν στο σύνολο pay-as-you-go ή στο σύνολο της άδειας χρήσης σου.

💼 Άδειες χρήσης QuizWitz PRO​

Αν φιλοξενείς κουίζ τακτικά, μια άδεια χρήσης QuizWitz PRO σου δίνει μόνιμα ενεργά Seats που είναι πάντα διαθέσιμα - δεν χρειάζεται να τα ενεργοποιείς χειροκίνητα.

Οι διαθέσιμες βαθμίδες άδειας χρήσης περιλαμβάνουν:

  • PRO-50: 50 μόνιμα ενεργά Seats
  • PRO-100: 100 μόνιμα ενεργά Seats
  • PRO-500: 500 μόνιμα ενεργά Seats
  • PRO-1K: 1000 μόνιμα ενεργά Seats
  • PRO-2K: 2000 μόνιμα ενεργά Seats

Αυτά τα Seats είναι ιδανικά για επαναλαμβανόμενες εκδηλώσεις, μεγαλύτερες ομαδικές διοργανώσεις ή επαγγελματικούς χώρους.

⚠️ Σημαντικό: Αν χρειάζεται να φιλοξενήσεις ένα κουίζ με περισσότερους παίκτες από όσους επιτρέπει η άδεια χρήσης σου, πρέπει να κάνεις Ενεργοποίηση Seats Pay-as-you-go για ολόκληρο τον αριθμό των παικτών. Τα Seats της άδειας χρήσης σου δεν προστίθενται στα ενεργοποιημένα Seats σου - τα αντικαθιστούν πλήρως.

💳 Pay-as-you-go και credits​

Για μεμονωμένες ή περιστασιακές εκδηλώσεις, μπορείς να ενεργοποιήσεις Seats pay-as-you-go αντί να αγοράσεις άδεια χρήσης. Αυτό σου δίνει ευελιξία χωρίς μακροπρόθεσμη δέσμευση.

  • Τα Seats ενεργοποιούνται με QuizWitz Credits, τα οποία μπορείς να αγοράσεις εκ των προτέρων.
  • Υπάρχουν εκπτώσεις ποσότητας όταν αγοράζεις credits σε μεγάλες ποσότητες.
  • Κάθε άδεια χρήσης PRO περιλαμβάνει αξία σε δωρεάν credits.
  • Αν δεν είσαι σίγουρος πόσοι παίκτες θα συμμετάσχουν:
    • Μπορείς να περιμένεις μέχρι να συνδεθούν όλοι πριν ενεργοποιήσεις Seats.
    • Ή ενεργοποίησε περισσότερα Seats από όσα χρειάζεσαι - τα αχρησιμοποίητα Seats επιστρέφονται αυτόματα σε credits όταν λήξουν.

⏳ Διάρκεια των Seats (pay-as-you-go)​

  • Τα Seats pay-as-you-go μένουν ενεργά για 48 ώρες μετά την ενεργοποίηση.
  • Μέσα σε αυτό το διάστημα μπορείς:
    • Να τρέξεις πολλά κουίζ ή παιχνίδια
    • Να δοκιμάσεις το κουίζ σου με μεγαλύτερες ομάδες
    • Να φιλοξενήσεις πολυήμερες εκδηλώσεις σε ένα Σαββατοκύριακο

📉 Τιμές για μεγάλες ομάδες​

  • Οι τιμές των Seats μειώνονται για μεγαλύτερο αριθμό παικτών, κάνοντας τις μεγάλες εκδηλώσεις πιο οικονομικές.

⚠️ Ειδική περίπτωση: λειτουργία Whitelabel​

  • Τα παιχνίδια σε λειτουργία Whitelabel απαιτούν 2 Seats ανά παίκτη αντί για ένα.

Παράδειγμα: Ένα παιχνίδι Whitelabel 100 παικτών απαιτεί 200 Seats.

Το QuizWitz PRO σου δίνει ευέλικτα και επαγγελματικά εργαλεία για να διοργανώνεις εκδηλώσεις κάθε μεγέθους - είτε ενεργοποιείς Seats όποτε τα χρειάζεσαι είτε βασίζεσαι σε μια άδεια χρήσης PRO για μόνιμη πρόσβαση.
