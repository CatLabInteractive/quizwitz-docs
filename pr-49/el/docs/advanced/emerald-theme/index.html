Θέμα Emerald

Το θέμα Emerald είναι ο πιο εύκολος τρόπος να προσαρμόσεις την εμφάνιση του παιχνιδιού σου στο QuizWitz. Από προεπιλογή, το θέμα έχει ένα καθαρό μπλε / πράσινο στυλ με ζωντανά χρώματα επιλογών, αλλά συνδυάζοντας συνημμένα κουίζ και τροποποιητές θέματος μπορείς να αλλάξεις την εμφάνισή του - ριζικά.

συμβουλή

Μπορείς να χρησιμοποιήσεις το εργαλείο δοκιμής θεμάτων για να δεις πώς θα φαίνονται οι ρυθμίσεις σου.

Επιλογή του θέματος Emerald​

Στις Ρυθμίσεις κουίζ, επίλεξε Θέμα και ενεργοποίησε το Emerald.

Μπορείς να δοκιμάσεις ένα κουίζ με το θέμα Emerald εδώ.

Συνημμένα​

Συνημμένα κουίζ​

Ο πιο εύκολος τρόπος για να αλλάξεις την εμφάνιση και την αίσθηση του παιχνιδιού είναι να επισυνάψεις εικόνες στο κουίζ σου. Άνοιξε τις Ρυθμίσεις κουίζ και κύλισε προς τα κάτω στην ενότητα Συνημμένα. Εδώ μπορείς να ανεβάσεις εικόνες που θα χρησιμοποιηθούν ως φόντο, λογότυπο πελάτη, οθόνες σύνδεσης και αναμονής (για κουίζ συνεδρίου και live) και πολλά άλλα.

Συνημμένα γύρου​

Μπορείς επίσης να ανεβάσεις εικόνες ή βίντεο που θα προβάλλονται πριν και μετά το παιχνίδι. Το ίδιο ισχύει και για τους γύρους: βρες μια εικόνα που θέλεις να χρησιμοποιήσεις ως εισαγωγή γύρου, πήγαινε στις ρυθμίσεις γύρου, απενεργοποίησε το Εμφάνιση εισαγωγής γύρου για να κρύψεις την προεπιλεγμένη εισαγωγή γύρου και ανέβασε την εικόνα ή το βίντεό σου στο Εμφάνιση πριν από τον γύρο. Όταν ξεκινά ο γύρος, η εικόνα ή το βίντεο θα εμφανίζεται στη θέση της προεπιλεγμένης εισαγωγής.

συμβουλή

Για τα καλύτερα αποτελέσματα, χρησιμοποίησε εικόνες και βίντεο ανάλυσης 1920 x 1080.

πληροφορία

Αφού πειραματιστούμε με τα συνημμένα, καταλήγουμε σε κάτι σαν αυτό.

Μουσική​

Όλη η μουσική του παιχνιδιού μπορεί επίσης να αντικατασταθεί με συνημμένα. Όλα τα αρχεία ήχου που ανεβαίνουν στις θέσεις κατά τη διάρκεια της ερώτησης θα παίζουν κατά την αντίστροφη μέτρηση της ερώτησης.

Τροποποιητές του θέματος Emerald​

Εκτός από τα συνημμένα, μπορείς επίσης να τροποποιήσεις το θέμα Emerald με παραμέτρους ερωτήματος (query parameters). Αυτές είναι παράμετροι που μπορείς να προσθέσεις στο URL της ενότητας Προχωρημένες επιλογές παιχνιδιού - και αλλάζουν την εμφάνιση του θέματος.

Για τον σκοπό αυτό θα ξεκινήσουμε από ένα παράδειγμα κουίζ (χωρίς συνημμένα):
https://play.quizwitz.com/11486:gFUabUFh7i/emerald-theme-tutorial-default

Όταν ξεκινήσεις το παραπάνω κουίζ, το παιχνίδι θα έχει το προεπιλεγμένο στυλ Emerald. Ας το αλλάξουμε.

συμβουλή

Ο πιο εύκολος τρόπος για να πειραματιστείς με αυτές τις παραμέτρους είναι το εργαλείο δοκιμής θεμάτων.
Όταν τελειώσεις με τους πειραματισμούς, μπορείς να αντιγράψεις και να επικολλήσεις τις παραμέτρους στο URL των προχωρημένων επιλογών παιχνιδιού σου.

Οι διαθέσιμοι τροποποιητές είναι:

  • backgroundColor
  • mainColor
  • accentColor
  • timerBackgroundColor
  • headerTextColor
  • optionTextColor
  • optionColors (4 χρώματα, χωρισμένα με κόμμα)
  • optionBorderColors (4 χρώματα, χωρισμένα με κόμμα)

Επιπλέον, μπορείς να ορίσεις μια προεπιλεγμένη γραμματοσειρά:

  • defaultFont
  • headerFont

Αυτές οι γραμματοσειρές πρέπει να είναι URL προς δημόσια διαθέσιμα αρχεία γραμματοσειρών.

Καθένας από αυτούς τους τροποποιητές μπορεί να περιέχει ένα μόνο χρώμα σε δεκαεξαδική μορφή HTML (ff0000) ή μια γραμμική διαβάθμιση, αν δώσεις πολλά χρώματα χωρισμένα με το σύμβολο μείον ( - για παράδειγμα ff1b6b-45caff). (Σημείωσε ότι δεν πρέπει να προστεθεί το σύμβολο #.)

σημείωση

Οι παράμετροι ερωτήματος πρέπει να ξεκινούν με ερωτηματικό ( ? ) και κάθε παράμετρος πρέπει να χωρίζεται με ένα σύμβολο & ( & ). Για περισσότερες πληροφορίες σχετικά με τις παραμέτρους ερωτήματος, επισκέψου τη Wikipedia.

Προσθέτοντας αυτές τις παραμέτρους στο URL του παιχνιδιού σου, μπορείς να αλλάξεις τα χρώματα του θέματος:
https://play.quizwitz.com/11486:gFUabUFh7i/emerald-theme-tutorial-default?backgroundColor=ff1b6b-45caff&accentColor=00ff87&mainColor=ffffff&timerBackgroundColor=fff95b
