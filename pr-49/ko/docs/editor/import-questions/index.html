📥 문제 가져오기

QuizWitz에서 라운드에 문제를 빠르게 추가하는 방법은 두 가지입니다.

  • QuizWitz 라이브러리에서 기존 콘텐츠 가져오기
  • 스프레드시트에서 문제 목록 붙여넣기

두 옵션 모두 어느 라운드에서든 사용할 수 있습니다.

📚 QuizWitz 라이브러리에서 가져오기​

QuizWitz 라이브러리 탭에서 내가 만들었거나 다른 제작자가 만든 문제, 라운드, 퀴즈를 검색하고 가져올 수 있습니다.

  1. 콘텐츠를 가져올 라운드를 여세요
  2. QuizWitz 라이브러리 탭을 클릭하세요
  3. 언어, 컬렉션, 유형, 카테고리, 태그 같은 필터를 사용하세요
  4. 항목을 하나 이상 선택하세요
  5. 항목 X개 추가를 클릭하여 선택한 콘텐츠를 퀴즈에 넣으세요

✅ 품질 좋은 콘텐츠를 재사용하거나 여러 공개 Round-About을 하나의 큰 퀴즈로 조합할 때 이 방법을 사용하세요.

📋 스프레드시트에서 가져오기​

많은 문제를 한 번에 빠르게 만들려면 스프레드시트에서 가져오기 탭을 사용하세요.

  1. 라운드를 여세요
  2. 스프레드시트에서 가져오기 탭을 클릭하세요
  3. 탭으로 구분된 값의 행을 붙여넣으세요(Excel, Google Sheets 등에서 복사)
  4. 문제 가져오기를 클릭하세요

🗂️ 붙여넣기 형식​

각 행에는 다음 열이 정확히 이 순서대로 있어야 합니다.

  1. 짧은 문제 - 플레이어 화면에 표시됩니다
  2. 정답
  3. 오답 1(주관식 문제는 비워 두세요)
  4. 오답 2
  5. 오답 3
  6. 짧은 피드백 - 답한 후 플레이어 화면에 표시됩니다
  7. 긴 문제 (선택 사항) - 퀴즈마스터 화면에 표시됩니다
  8. 긴 피드백 (선택 사항) - 퀴즈마스터가 소리 내어 읽을 해설

📌 마지막 두 열은 QuizWitz Live에서만 사용되지만, 비워 두더라도 반드시 포함해야 합니다.

✅ 가져온 후​

라이브러리에서 가져오든 스프레드시트에서 가져오든:

  • 문제의 형식과 명확성을 검토하세요
  • 카테고리, 라운드 유형, 첨부 파일 같은 메타데이터를 업데이트하세요
  • 퀴즈 저장을 잊지 마세요

📘 문제를 더 멋지게 다듬고 싶으신가요? 문제 작성 가이드에서 계속 알아보세요.
