토너먼트

이 튜토리얼에서는 QuizWitz 토너먼트 모드를 사용하는 방법을 알려 드립니다. 토너먼트 모드에서는 플레이어가 원할 때 언제든 자신의 기기로 퀴즈에 참가해 플레이할 수 있습니다. 플레이어의 점수는 행사장에 표시할 수 있는 전체 리더보드에 기록됩니다.

📝 퀴즈 만들기​

토너먼트 퀴즈를 만들 때는 짧고 흥미롭게 구성하세요. 방문객이 퀴즈에 시간을 너무 많이 써야 하면 끝까지 마치지 못할 수 있습니다.
퀴즈를 끝까지 마친 플레이어만 리더보드에 올라갑니다.

🎲 무작위 문제 선택​

게임이 문제 풀에서 무작위로 문제를 고르게 하면 매 게임이 새롭게 느껴지고, 다시 찾아온 플레이어도 다른 문제를 받습니다.

구성 예시:

  • 만들기 메뉴에서 퀴즈를 선택하고 퀴즈 이름을 정합니다. 올바른 언어를 설정합니다.
  • 라운드 3개를 만들고 이름을 정합니다(예: 라운드 1, 라운드 2, 라운드 3).
  • 각 라운드 설정(톱니바퀴 아이콘)에서 x개 문제만 표시를 켜고 5로 설정합니다.
  • 게임이 항상 같은 문제를 먼저 고르지 않도록 문제 순서 무작위를 켭니다.

퀴즈의 모든 라운드에 이 단계를 반복합니다.

🚀 토너먼트 시작하기​

토너먼트는 고급 게임 옵션 메뉴에서만 시작할 수 있습니다.

  1. 퀴즈 플레이를 선택하고 고급 게임 옵션을 고릅니다.

  2. 팝업에서 토너먼트 게임 모드를 선택하고 플레이 링크 생성을 클릭합니다.

이제 링크 두 개를 받게 됩니다:

  • 플레이어 링크 - 플레이어와 공유하세요(또는 플레이어가 리더보드의 QR 코드를 스캔하게 하세요).
  • 리더보드 링크 - 행사장의 디스플레이에서 열어 실시간 순위와 플레이어가 스캔해 참가할 수 있는 QR 코드를 보여 주세요.

🏆 리더보드 실행하기​

리더보드를 실행하려면 로그인해야 합니다:

  1. 로그인하여 프로필 추가를 클릭하고 비밀번호를 입력합니다.

  2. 창에서 프로필을 선택해 리더보드를 시작합니다.

첫 플레이어들이 게임을 마치면 점수가 실시간으로 표시됩니다:

📧 확인 이메일​

플레이어 링크와 리더보드 링크가 모두 담긴 이메일도 받게 됩니다 - 링크를 잃어버리지 않도록 편리합니다!
