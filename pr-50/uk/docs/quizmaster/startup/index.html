🚀 Запуск - Проведення квізу з QuizWitz Live

Вітаємо в QuizWitz Live - професійному способі проводити квізи для команд, трансляцій і заходів наживо. Дотримуйся цього посібника, щоб запустити свій квіз за допомогою застосунку квізмайстра.

🖥️ Запуск QuizWitz Live​

Гру QuizWitz Live можна почати з редактора квізів або безпосередньо зі своєї колекції квізів.

  • У редакторі квізів натисни «Запустити QuizWitz Live»

  • У своїй колекції натисни значок Live, щоб запустити

🔐 Підключення за кодом квізмайстра​

Після запуску на екрані з'явиться код квізмайстра. Не показуй цей код гравцям - він потрібен, щоб підключити твій пристрій для презентації до гри.

  • Відкрий quizwitz.tv на пристрої квізмайстра та введи код квізмайстра.
  • З'явиться інтерфейс застосунку квізмайстра, у якому ти керуєш грою.
  • Для мобільності ми радимо планшет або смартфон, але ноутбук теж підійде.

Після підключення код квізмайстра зникає з екрана. Тепер можна показувати екран гри на проєкторі або почати трансляцію.

⚠️ Увага! Якщо екран гри не активний - наприклад, якщо ти перемикаєш вкладки або згортаєш його, - гра автоматично стає на паузу.
Коли це стається:

  • Застосунок квізмайстра теж стає на паузу
  • Щоб продовжити, спершу переконайся, що екран гри знову активний
  • Потім наведи курсор на екран, щоб з'явилося нижнє меню, і натисни кнопку паузи, щоб продовжити

🎮 Вибір режиму гри​

Після підключення вибери один із двох режимів гри:

Коди команд​

  • Кожна команда отримує унікальний код, який можна відкрити на кількох пристроях.
  • Найкраще підходить для квізів із попередньо зареєстрованими командами, коли назви команд відомі заздалегідь.
  • Дає змогу змінити пристрій - корисно, якщо посеред квізу розрядився акумулятор.

Спільний код гри​

  • Усі приєднуються за допомогою одного спільного коду гри.
  • Ідеально для невимушених або відкритих заходів.
  • Попередня реєстрація не потрібна - гравці можуть приєднатися будь-коли, доки не заповнено всі активні Seats.

Переконайся, що ти ввійшов у систему, щоб мати доступ до свого квізового контенту.

👥 Проведення гри з кодами команд​

Якщо ти використовуєш коди команд, спершу створи команди в застосунку квізмайстра:

  • Додай назви команд
  • Натисни «Згенерувати коди», щоб створити коди доступу

Також можна зарезервувати коди заздалегідь - докладніше про це в розділі порад і хитрощів.

Обов'язково збережи такі коди:

  • Код квізмайстра - щоб керувати квізом
  • Код журі - для ручного коригування балів
  • Код режисера - щоб керувати візуальними та технічними елементами

Надішли коди команд гравцям електронною поштою або в роздруківках.

Коли будеш готовий, натисни «Завантажити квіз», дочекайся завантаження ресурсів, а потім натисни «Почати», щоб розпочати.

👤 Проведення гри зі спільним кодом гри​

Зі схемою спільного коду гри:

  • Ти отримаєш коди квізмайстра, журі та режисера, а також один код гри для гравців.
  • Код гри з'являється на екрані гри - покажи його аудиторії або транслюй.
  • Гравці можуть приєднатися будь-коли, доки не буде досягнуто ліміту активних Seats.

Коли гравці приєдналися:

  1. Натисни «Завантажити квіз»
  2. Натисни «Почати квіз» і підтвердь
  3. Код гри залишається видимим для тих, хто запізнився

🎟️ Активація Seats​

Перед початком потрібно перевірити доступні Seats.

  • Після вибору режиму гри з'являється огляд
  • Якщо тобі потрібно більше Seats, активуй їх на app.quizwitz.com/seats

▶️ Початок гри​

Коли налаштування завершено, натисни «Почати квіз» у застосунку квізмайстра, щоб почати гру.

Тепер ти готовий розважати свою аудиторію бездоганним досвідом QuizWitz Live!
