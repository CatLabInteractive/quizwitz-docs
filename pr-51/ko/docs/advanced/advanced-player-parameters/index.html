⚙️ 고급 매개변수

쿼리 문자열 매개변수를 사용하여 QuizWitz 게임 클라이언트의 동작을 커스터마이즈할 수 있습니다. 이 매개변수는 고급 게임 설정 기능을 사용하여 모든 게임 링크에 추가할 수 있습니다.

예:

https://play.quizwitz.com/13305:qyHBEVVBqT?theme=emerald

📘 쿼리 문자열이란?

사용 가능한 매개변수:​

매개변수기본값예설명
language(브라우저)en기본 언어로 불러와 사용할 ISO-639 언어 코드
themequiztedemerald불러올 테마의 이름(또는 승인된 URL)
reservation/abcdef사용할 예약 토큰(라이브 게임에서)
remotequizwitz.tvquizwitz.tv사용할 CatLab Remote 서버
server/10사용할 CatLab Remote 서버 ID(자동 검색 사용 시)
publisher/QuizWitz게임을 호스트하는 프로필의 이름입니다. 화면을 커스터마이즈하는 데 사용됩니다
smileys10게임에서 스마일리를 비활성화하려면 0으로 설정하세요
outroPlayers125,4,3,1,2게임 아웃트로에서 발표할 플레이어 수(숫자) 또는 플레이어 순서(쉼표로 구분한 순위 목록)를 정의합니다.
focusPositions/50,100퀴즈마스터 앱에 표시할 추가 순위 목록을 정의합니다
translations10불러오는 퀴즈의 번역을 불러오지 않으려면 0으로 설정하세요
cycleTranslations01문제마다 퀴즈의 사용 가능한 모든 언어를 순환하려면 1로 설정하세요
showLongQuestions01게임 화면에 “긴 문제”를 표시하려면 1로 설정하세요
forcePiecharts01모든 피드백을 항상 원형 차트로 표시하려면 1로 설정하세요
forceNoPiecharts01피드백을 원형 차트로 묶지 않으려면 1로 설정하세요.
piechartPercentages01모든 원형 차트에서 절댓값 대신 백분율을 표시하려면 1로 설정하세요
monitors/nl,fr설정하면, 라이브 게임에서 현지 퀴즈마스터를 위해 해당 언어로 “모니터”를 표시하는 별도의 코드가 생성됩니다.
allowLogin10사용자의 로그인을 허용하지 않으려면 0으로 설정하세요
tracker10모든 추적을 비활성화하려면 0으로 설정하세요. 퀴즈 보고서를 이용할 수 없게 됩니다
random01“무작위 퀴즈”를 불러오려면 1로 설정하세요
delay030000모든 플레이어 상호작용을 지연할 시간(밀리초)을 설정합니다(라이브 스트리밍용)
countdown1060프레젠테이션 모드에서 게임이 “카운트다운”할 시간(초)을 설정합니다.
autoCountdown01프레젠테이션 모드에서 첫 플레이어가 참여한 후 카운트다운을 자동으로 시작하려면 1로 설정하세요.
autoRestart01게임이 끝난 후 자동으로 다시 시작하려면 1로 설정하세요.
waitForPlayers01autoCountdown이 활성화되어 있을 때 플레이어를 기다리지 않으려면 1로 설정하세요
askEmail10프레젠테이션 모드에서 사용자 이메일 주소를 묻지 않으려면 0으로 설정하세요.
beacon/my-beacn퀴즈마스터 앱을 자동으로 연결하는 데 사용할 수 있는 CatLab Remote 비컨 토큰을 설정합니다.
rounds57무작위 퀴즈에서 생성할 라운드 수를 설정합니다.
questions77무작위 퀴즈에서 각 라운드마다 생성할 문제 수를 설정합니다.
showListenQuotes10“재미있는” “잘 들어 주세요” 인용문을 비활성화하려면 0으로 설정하세요.
shared/123:abcdef공유된 퀴즈 또는 Round-About의 액세스 토큰입니다.
music10모든 (게임) 음악을 비활성화하려면 0으로 설정하세요. 업로드한 오디오는 계속 재생됩니다.
connectMusic10“접속” 단계에서 재생되는 (게임) 음악을 비활성화하려면 0으로 설정하세요.
slideshowVideoInterval300300접속 화면 단계에 동영상을 업로드한 경우, 각 동영상 재생 사이의 간격(초)을 정의합니다.
slideshowImageInterval2060접속 화면 단계에 이미지를 업로드한 경우, 각 이미지를 표시할 시간(초)을 정의합니다.
skipOnAllAnswered10퀴즈의 skipOnAllAnswered 설정을 무시하려면 0으로 설정하세요
departments1A,B,C부서를 불러오지 않으려면 0으로 설정하세요. 쉼표로 구분한 이름 목록으로 설정하면, 접속하는 모든 플레이어가 무작위 부서에 자동으로 배정됩니다.
showRankInDepartment10사용자가 부서 내 자신의 순위를 보지 못하게 하려면 0으로 설정하세요.
showDepartmentRanking10라운드 사이에 부서 순위를 표시하지 않으려면 0으로 설정하세요.
preloadVideo01모든 동영상 조각을 강제로 미리 불러오려면 1로 설정하세요.
n/_prompt_게임을 플레이하는 플레이어 그룹의 이름을 설정합니다(또는 _prompt_로 설정하여 이름을 요청합니다). 이 이름은 퀴즈 보고서로 전송됩니다.

💡 사용 팁​

  • 여러 매개변수는 &로 결합할 수 있습니다
  • 링크를 공유하거나 임베드할 때 고급 게임 설정과 함께 이 옵션을 사용하세요
  • 여러 옵션이 라이브 스트리밍 최적화나 다국어 이벤트에 유용합니다
