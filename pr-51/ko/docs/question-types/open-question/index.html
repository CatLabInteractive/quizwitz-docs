💬 주관식 문제

주관식 문제에서는 플레이어가 키보드로 답을 자유롭게 입력합니다. 이 모드는 이름, 숫자, 짧은 설명처럼 직접 쓴 답을 받고 싶은 문제에 안성맞춤입니다.

📝 작동 방식​

  • 문제: 자유 입력란에 구체적인 답을 요구합니다(예: “이 노래를 부르는 듀오는 누구일까요?”).
  • 답: 플레이어가 답을 입력합니다. 자동 채점을 위해 인정되는 답을 여러 개 지정할 수 있습니다.
  • 첨부 파일: 힌트로 오디오, 이미지 또는 동영상을 추가합니다(예: 음악 클립 재생).
  • 피드백: 플레이어는 답한 뒤 자신의 답이 정답으로 처리되었는지 확인합니다. 추가 피드백이나 해설을 제공할 수도 있습니다.

⚙️ 확장 설정​

주관식 문제에는 퀴즈에 맞출 수 있는 다양한 설정이 있습니다:

  • 인정되는 답 여러 개: 다른 철자, 약어 또는 동의어를 추가해 자동 채점을 더 유연하게 만듭니다.
  • 시간 기반 점수: 빠른 답에 보상을 줍니다(아래 “점수” 참고).
  • 자동 채점 강제: 이 옵션을 켜면 게임이 입력해 둔 목록을 바탕으로 정답을 자동으로 처리합니다.
    • 켜져 있지 않으면(대부분의 라이브 게임에서 기본값) 주관식 답은 심사위원 앱으로 직접 검토하고 채점해야 합니다.

이 옵션에 대한 자세한 내용은 문제 작성하기를 참고하세요.

🏆 주관식 문제의 점수​

주관식 문제의 점수 방식은 입력이 느린 사람에게도 공정하도록 설계되었습니다:

  • 시간 기반 점수는 밀리초 단위로 엄격하게 줄어드는 방식이 아니라 사용 가능한 점수를 구간으로 나눕니다.
  • 예를 들어 첫 번째 구간(예: 처음 5초) 안에 답하면 만점을 받고, 다음 구간에서는 80%를 받는 식입니다. 그래서 입력이 느린 사람이 받는 불이익이 줄어듭니다.
  • 기본적으로 점수의 **25%**만 속도에 따라 달라지고 나머지 **75%**는 고정되어 있으므로, 정답을 맞힌 사람은 입력 속도와 관계없이 점수 대부분을 받습니다.

⚙️ 팁: 라운드 옵션에서 점수 방식과 기타 설정을 더 조정할 수 있습니다.

🧑‍⚖️ QuizWitz Live의 심사위원 검토​

QuizWitz Live에서는 주관식 문제를 보통 심사위원 앱으로 직접 검토해야 합니다:

  • 심사위원 앱에서 심사위원은 주관식 답을 인정하거나 거부하거나 점수를 조정할 수 있습니다.
  • 발음이 비슷한 답과 대체 답을 인정하는 기능이 도움이 되지만, 공정한 점수와 창의적인 답을 위해서는 사람의 판단이 꼭 필요합니다.
  • 전체 안내와 기능은 심사위원 앱 문서를 참고하세요.

💡 좋은 주관식 문제를 위한 팁​

  • 구체적으로 쓰세요: 플레이어에게 무엇을 답해야 하는지 정확히 알려 주세요.
  • 변형을 예상하세요: 흔한 약어, 다른 철자 또는 동의어를 인정되는 답에 추가하세요.
  • 첨부 파일을 활용하세요: 오디오, 이미지 또는 동영상을 추가해 문제를 더 명확하고 흥미롭게 만드세요.
  • 심사위원과 미리 맞추세요: 주관적이거나 까다로운 답에서 무엇을 인정할지 심사위원이 알고 있는지 확인하세요.

첨부 파일과 피드백에 대한 자세한 내용은 첨부 파일 문서를 참고하세요.
