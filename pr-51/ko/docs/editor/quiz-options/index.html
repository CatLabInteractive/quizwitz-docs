⚙️ 퀴즈 옵션

퀴즈를 만들 때 퀴즈 설정 패널을 열어 전체 동작과 표시 옵션을 설정할 수 있습니다. 이 설정은 퀴즈 전체에 적용됩니다.

퀴즈 옵션 패널 열기퀴즈 설정 개요

🌐 언어​

퀴즈를 작성하는 언어를 선택하세요. 나중에 번역을 추가할 수 있습니다.

🎨 테마​

퀴즈의 시각 테마를 선택하세요.

  • 기본 테마는 QuizWitz입니다
  • 소속 조직에서 맞춤 테마를 이용할 수 있을 수도 있습니다
  • 테마는 배경, 색상, 레이아웃에 영향을 줍니다
  • 테마 목록 아래의 테마 맞춤 설정은 테마 테스터를 열어 테마의 색상과 글꼴을 바꾸고 퀴즈에 적용합니다(Premium, 컴퓨터에서)

📘 이 테마로 화면을 커스터마이즈하는 방법에 대한 자세한 내용은 Emerald 테마 문서를 참조하세요.

📎 첨부 파일​

특정 슬롯에 이미지, 오디오, 동영상을 넣어 퀴즈를 더 풍성하게 만드세요.

  • 퀴즈 전 - 퀴즈가 시작될 때 표시됩니다
  • 퀴즈 후 - 최종 결과 화면 뒤에 재생됩니다
  • 고객 로고 / 대체 로고 - 퀴즈 화면 전체에 표시됩니다
  • 대기 화면 - 라이브 게임에서 문제 사이에 표시됩니다(1920×1080 이미지 권장)
  • 배경 - 선택적으로 배경을 교체합니다(테마에 따라 다름)
  • 접속 화면 - 라이브 모드와 컨퍼런스 모드에서 사용됩니다.
    • 이미지 - 전체 화면 배경 이미지
    • 오디오 - 반복 재생되는 음악(최대 15분)
    • 동영상 - 5분마다 재생되며, 광고나 안내에 유용합니다

🎥 플레이어의 접속을 돕기 위해 미리 만들어 둔 안내 동영상을 사용할 수 있습니다.

  • 게임 아웃트로 중 - (오디오 전용) 우승자 공개 화면에서 재생됩니다

📘 기술적인 세부 사항과 권장 사항은 첨부 파일 가이드를 참조하세요.

🔧 추가 옵션​

게임 진행과 표시 여부를 커스터마이즈하는 선택 설정입니다.

  • 멀티플레이어 사용 - 기본값은 켜짐입니다. 친구들과 파티 플레이를 할 수 있습니다
  • 라운드 순서 무작위 - 라운드 순서를 섞습니다

    ⚠️ QuizWitz Live를 준비할 때는 권장하지 않습니다

  • 사용자의 문제 평가 허용 - 라운드가 끝난 후 플레이어가 각 문제를 평가할 수 있습니다
  • 댓글 사용 - 게시 후 피드백을 받을 수 있습니다
  • 모두 답하면 빨리 진행 - 활성화하면 모든 플레이어가 답했을 때 게임이 다음으로 넘어갑니다

    ⏱️ 시간 기반 점수를 사용할 때 권장합니다

📤 공유 또는 임베드​

고급 게임 설정이 적용된 공유 링크나 임베드 코드를 생성합니다.
