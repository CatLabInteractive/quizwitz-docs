🔄 라운드 옵션

각 라운드에는 특정한 유형이 있습니다. 기본값은 트리비아이지만, 사용 가능한 모든 유형을 테스트하고 실험해 보시기 바랍니다. 이 페이지에서는 라운드별로 설정할 수 있는 설정과 첨부 파일을 설명합니다.

📘 모든 라운드 유형에 대한 자세한 개요는 라운드 유형 문서를 참조하세요.

🔧 라운드 설정하기​

라운드 옵션을 설정하려면 라운드 패널의 톱니바퀴 아이콘을 클릭하세요.

라운드 옵션 열기라운드 설정 패널

⚙️ 일반 라운드 옵션​

대부분의 라운드 유형에서 다음 옵션을 사용할 수 있습니다.

  • 문제 _X_개만 표시 - 라운드의 문제를 특정 개수로 제한합니다
  • 문제 순서 무작위 - 라운드 안에서 문제 순서를 섞습니다
  • 라운드 인트로 표시 - 라운드가 시작되기 전에 애니메이션 제목을 표시합니다
  • 라운드 아웃트로 표시 (중간 점수) - 라운드가 끝나면 순위를 공개합니다
  • 모든 피드백을 한 화면에 묶기 - 라운드가 끝난 후 문제 피드백을 한 블록으로 모읍니다
  • 라운드가 끝날 때 모든 문제 피드백 표시 - 라운드가 끝날 때까지 문제 피드백을 미룹니다
  • 각 문제마다 피드백 강제 표시 - 즉시 피드백을 보장합니다

    ⚠️ 주관식 문제나 번개 라운드처럼 피드백이 원래 늦게 표시되는 라운드 유형과 문제 유형에서만 적용됩니다.

📘 피드백 타이밍과 동작에 대한 자세한 내용은 문제 유형을 참조하세요.

🏆 점수 옵션​

QuizWitz는 모든 플레이어에게 공정하고 흥미롭도록 유연한 점수 방식을 제공합니다.

  • 시간 기반 점수 - 더 빨리 답한 플레이어가 더 많은 점수를 얻습니다.

    • 대부분의 문제 유형에서 시간 기반 점수는 마이크로초 단위로 계속 줄어듭니다. 빨리 답할수록 더 많은 점수를 얻습니다.
    • 주관식 문제의 경우 시간 기반 점수가 구간으로 나뉩니다. 예: 첫 번째 구간(예: 처음 몇 초)의 답변은 시간 기반 점수의 **100%**를, 다음 구간은 **80%**를 받는 식입니다. 타자가 느린 플레이어에게도 공평한 조건을 만들어 줍니다.

  • 시간 기반 점수의 고정 점수 비율 - 총점 중 속도의 영향을 받는 비중을 직접 정합니다.

    • 기본적으로 점수의 **75%**는 고정 점수입니다(속도와 관계없이 정답을 맞힌 모든 사람이 받습니다).
    • 나머지 **25%**만 플레이어의 응답 속도에 따라 달라집니다.

💡 이 설정을 조정하면 퀴즈 스타일에 따라 라운드를 더 지식 중심으로 또는 더 속도 중심으로 만들 수 있습니다.

이 점수 옵션은 라운드를 편집할 때 라운드 옵션 패널에서 찾을 수 있습니다.

💬 라운드 해설​

일부 라운드 유형과 점수 옵션은 첫 문제 전에 게임 화면에 짧은 해설을 표시합니다. 예를 들어 라운드가 스트라이크 점수 방식을 사용하면 *“연속으로 정답을 맞혀 더 높은 Level에 오르고 보너스 점수를 받으세요.”*라는 해설이 표시됩니다. 라운드 시작 부분에서 + 라운드 해설을 클릭하면 이 문구를 직접 작성한 내용으로 바꿀 수 있습니다. 기본 해설이 없는 일반 트리비아 라운드를 설명하는 데에도 사용할 수 있습니다.

  • 라운드 유형의 기본 해설을 유지하려면 칸을 비워 두세요.
  • 라운드 해설은 다른 텍스트와 마찬가지로 번역됩니다. 퀴즈의 모든 언어로 추가하세요.
  • 퀴즈마스터가 퀴즈를 진행하면 게임 화면에서 라운드 해설을 건너뜁니다. 대신 아래의 퀴즈마스터 대본을 사용하세요.

📜 퀴즈마스터 안내​

라운드 시작 시 퀴즈마스터 앱에만 표시되는 라운드 소개 문구(퀴즈마스터 대본)를 직접 추가할 수 있습니다. 퀴즈마스터에게 내용을 안내하거나 개성을 더하는 데 활용하세요.

📎 첨부 파일​

특정 시점에 표시되는 첨부 파일로 라운드를 더 풍성하게 만드세요.

  • 라운드 전 - 라운드 인트로 애니메이션 뒤에 표시됩니다
  • 라운드 후 - 라운드 아웃트로 뒤에 표시됩니다
  • 라운드 아웃트로 전 - 마지막 문제 뒤, 아웃트로 직전에 표시됩니다
  • 라운드 아웃트로 중 - (오디오 전용) 순위가 표시되는 동안 재생됩니다
  • ...

📘 지원되는 파일 형식과 사용 팁은 첨부 파일 가이드를 참조하세요.
