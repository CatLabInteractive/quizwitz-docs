✍️ Σύνταξη ερωτήσεων

Ώρα για δημιουργικότητα! Είτε φτιάχνεις ένα ολοκληρωμένο κουίζ είτε ένα Round-About, οι δυνατές και διασκεδαστικές ερωτήσεις είναι η καρδιά ενός σπουδαίου παιχνιδιού.

Για να ξεκινήσεις, κάνε κλικ στο Προσθήκη νέας ερώτησης. Μπορείς να προσθέσεις όσες θέλεις.

💾 Μην ξεχνάς να αποθηκεύεις τη δουλειά σου τακτικά και να δοκιμάζεις το κουίζ σου οποιαδήποτε στιγμή για να δεις πώς παίζεται!

⚙️ Ρυθμίσεις ερώτησης​

Κάνε κλικ στο εικονίδιο με το γρανάζι στην επάνω αριστερή γωνία μιας ερώτησης για να ανοίξεις τον πλήρη πίνακα ρυθμίσεών της.

🎮 Τύπος και βαθμολόγηση​

  • Τύπος ερώτησης - Επίλεξε πώς παίζεται η ερώτηση (π.χ. πολλαπλή επιλογή, ανοιχτή απάντηση, γρίφος)
    → Μάθε περισσότερα στους τύπους ερωτήσεων
  • Πόντοι - Όρισε πόσους πόντους αξίζει μια σωστή απάντηση
  • Χρονόμετρο ερώτησης - Ρύθμισε το χρονικό όριο με το ρυθμιστικό

🧩 Ρυθμίσεις συμπεριφοράς στο παιχνίδι​

Προσάρμοσε πώς συμπεριφέρεται η ερώτηση κατά τη διάρκεια του παιχνιδιού:

  • Βαθμολόγηση με βάση τον χρόνο - Επιβράβευσε τους παίκτες που απαντούν πιο γρήγορα
  • Πολλές σωστές απαντήσεις - Επίτρεψε περισσότερες από μία έγκυρες επιλογές
  • Τυχαία σειρά απαντήσεων - Ανακάτεψε τις επιλογές στην οθόνη
  • Διακοπή χρονομέτρου όταν απαντήσουν όλοι - Συνέχισε μόλις έρθουν όλες οι απαντήσεις
  • Εμφάνιση αποτελεσμάτων ερώτησης - Εμφάνισε την ανατροφοδότηση μετά την ερώτηση (ή απενεργοποίησέ την)
  • Υποχρεωτικά αποτελέσματα μετά την ερώτηση - Ισχύει μόνο όταν η ανατροφοδότηση κανονικά θα καθυστερούσε (π.χ. σε γύρους αστραπή ή ανοιχτές ερωτήσεις). Στις κανονικές ερωτήσεις χωρίς κριτική επιτροπή, η ανατροφοδότηση εμφανίζεται αυτόματα μετά από κάθε ερώτηση.

🎤 Περιεχόμενο για τον quizmaster​

Αυτά τα πεδία ελέγχουν τι εμφανίζεται στην Quizmaster App και στην οθόνη παιχνιδιού:

  • Οθόνη παιχνιδιού - Ανατροφοδότηση ερώτησης - Εμφανίζεται σε όλους τους παίκτες μετά την αποκάλυψη της ανατροφοδότησης
  • Quizmaster - Μεγάλη ερώτηση - Μια εκδοχή της ερώτησης που διαβάζει δυνατά ο quizmaster
  • Quizmaster - Μεγάλη ανατροφοδότηση - Κείμενο που μπορεί να διαβάσει ο quizmaster μετά την αποκάλυψη της σωστής απάντησης

📝 Αυτά τα πεδία κάνουν τις live παρουσιάσεις πιο ζωντανές και προσεγμένες.

🖼️ Προσαρμοσμένη προβολή​

Ορισμένα θέματα μπορούν να εμφανίσουν μια ερώτηση σε περισσότερες από μία διατάξεις οθόνης. Όταν το θέμα του κουίζ τις προσφέρει, στις ρυθμίσεις της ερώτησης εμφανίζεται η επιλογή Προσαρμοσμένη προβολή:

  • Προεπιλογή - Το κείμενο της ερώτησης, οι επιλογές απάντησης και το συνημμένο μοιράζονται την οθόνη ως συνήθως
  • Συνημμένο σε πλήρη οθόνη - Η εικόνα ή το βίντεο στη θέση Κατά την ερώτηση γεμίζει όλη την οθόνη παιχνιδιού· το κείμενο της ερώτησης και οι επιλογές δεν εμφανίζονται. Οι παίκτες εξακολουθούν να διαβάζουν την ερώτηση και να απαντούν στη δική τους συσκευή. Ιδανικό για ερωτήσεις με εικόνα τύπου «Τι είναι αυτό;» και για ερωτήσεις με βίντεο.
  • Συνημμένο σε πλήρη οθόνη χωρίς χρονόμετρο - Το ίδιο, αλλά κρύβεται και η αντίστροφη μέτρηση (θέμα Emerald)

ℹ️ Μια προσαρμοσμένη προβολή αλλάζει μόνο μια ερώτηση που έχει εικόνα ή βίντεο στη θέση Κατά την ερώτηση. Δεν είναι το ίδιο με την Εμφάνιση στις συσκευές των παικτών (δες τα συνημμένα), που αντικατοπτρίζει μια εικόνα στα κινητά των παικτών.

📘 Οι διαθέσιμες προβολές εξαρτώνται από το θέμα - δες τις σελίδες θέμα Emerald και θέματα.

📎 Συνημμένα​

Μπορείς να εμπλουτίσεις τις ερωτήσεις με εικόνες, βίντεο ή ήχο. Κάθε συνημμένο μπορεί να εμφανιστεί σε συγκεκριμένα σημεία:

  • Πριν / Κατά τη διάρκεια / Μετά την ερώτηση - Εμφανίζεται γύρω από τη στιγμή που παρουσιάζεται η ερώτηση
  • Πριν / Κατά τη διάρκεια / Μετά την ανατροφοδότηση - Εμφανίζεται όταν αποκαλύπτονται τα αποτελέσματα
  • ...

🧠 Τα συνημμένα είναι ιδιαίτερα χρήσιμα για να χτίσεις αγωνία, να εικονογραφήσεις απαντήσεις ή να δώσεις πλαίσιο.

Μπορείς να προσθέσεις πολλά συνημμένα σε κάθε θέση.

⚡ Στο QuizWitz Live (PRO): ο quizmaster μπορεί να επιλέξει ποιο συνημμένο θα εμφανίσει σε κάθε στιγμή.
🎮 Σε παιχνίδια χωρίς quizmaster (Παιχνίδι παρέας, λειτουργία συνεδρίου, Ένας παίκτης): όλα τα συνημμένα μιας θέσης εμφανίζονται ταυτόχρονα.

📘 Μάθε περισσότερα για τους υποστηριζόμενους τύπους αρχείων, συμβουλές χρονισμού και περιορισμούς στον οδηγό συνημμένων.

💡 Επαγγελματική συμβουλή: Διάλεξε τη σωστή στιγμή​

  • Θέλεις να δείξεις οπτικά τη σωστή απάντηση; → Χρησιμοποίησε το Μετά την ερώτηση
  • Θέλεις να χτίσεις αγωνία πριν από την αποκάλυψη της ανατροφοδότησης; → Χρησιμοποίησε το Πριν από την ανατροφοδότηση
  • Θέλεις να προσθέσεις επιπλέον πληροφορίες ή βάθος; → Χρησιμοποίησε το Μετά την ανατροφοδότηση

Στη συνέχεια: Μάθε περισσότερα για τους διάφορους τύπους ερωτήσεων και πώς να οργανώσεις τους τύπους γύρων σου για μέγιστο αποτέλεσμα.
