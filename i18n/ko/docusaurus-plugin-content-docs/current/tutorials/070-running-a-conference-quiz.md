# 컨퍼런스 퀴즈 운영하기

이 가이드에서는 컨퍼런스 부스나 이벤트에서 QuizWitz 퀴즈를 운영하는 데 필요한 모든 것을 퀴즈 링크를 여는 것부터 최종 순위까지 차근차근 안내합니다.

---

## 준비물

시작하기 전에 다음이 준비되어 있는지 확인하세요:

- 안정적인 인터넷 연결
- 퀴즈 URL(미리 전달받은 것)
- 플레이어가 볼 화면에 연결된 노트북
- **Google Chrome** - Safari나 Edge 같은 다른 브라우저에서는 제대로 작동하지 않을 수 있습니다

---

## 퀴즈 처음 열기

1. Google Chrome에서 퀴즈 URL을 엽니다.  
   Chrome에서 자동으로 열리지 않으면 링크를 마우스 오른쪽 버튼으로 클릭하고 **연결 프로그램 → Google Chrome**을 선택합니다.

2. 백분율이 표시되는 검은색 로딩 화면이 나타납니다. 몇 초밖에 걸리지 않습니다.

3. 로드가 끝나면 게임 화면이 나타납니다. 로그인하라는 메시지가 나타나면 **로그인**을 클릭하세요 - 두 번째 탭이 열립니다.
   - 로그인 페이지에서 **로그인**을 클릭하고 전달받은 로그인 정보를 입력합니다.
   - 로그인하면 탭이 자동으로 닫히고 퀴즈 로딩이 마무리됩니다.

4. 로딩이 끝나면 퀴즈 환영 화면이 나타납니다.

5. 화면 위로 커서를 움직이면 하단에 컨트롤 바가 나타납니다.  
   오른쪽의 **사각형 아이콘**을 클릭해 전체 화면 모드로 전환합니다.  
   이제 게임 화면에서 퀴즈를 플레이할 준비가 되었습니다.

:::tip
언제든 전체 화면을 끝내려면(예: 다른 창으로 전환하려면) **Esc**를 누르세요.
:::

---

## 다른 그룹을 위해 퀴즈 다시 시작하기

게임이 끝난 뒤 다시 플레이하려면 몇 가지 방법이 있습니다:

- **페이지 새로 고침** - Chrome 도구 모음의 새로고침 아이콘을 클릭하세요(전체 화면을 끝내려면 먼저 Esc를 눌러야 할 수 있습니다).
- **S 누르기** - 퀴즈가 끝난 뒤 키보드에서 **S**를 누르면 시작 화면으로 돌아갑니다.

새 게임을 시작할지 묻는 팝업이 나타나면 **예, 새 게임 시작**을 클릭합니다.

퀴즈가 다시 로드되면 로그인 정보가 유지되어 바로 환영 화면으로 이동합니다. 컨트롤 바에서 다시 전체 화면으로 전환하세요.

---

## 플레이어 참가

플레이어는 자신의 스마트폰으로 다음 두 가지 방법 중 하나로 참가합니다:

- 브라우저에서 \*\*www.quizwitz.tv\*\*에 접속
- 게임 화면에 표시된 **QR 코드**를 스캔

참가 화면에서 플레이어는:

1. 게임 화면에 표시된 **8자리 코드**를 입력합니다.
2. **이름과 이메일 주소**를 입력합니다.
3. **개인정보 확인란**을 체크합니다.
4. **준비 완료**를 탭합니다.

참가하면 플레이어의 휴대폰에 대기 메시지가 표시됩니다. 게임 화면에 접속한 플레이어 수가 표시됩니다.

:::note
최대 플레이어 수에 도달하지 않았다면 플레이어는 언제든 참가할 수 있습니다.
:::

---

## 게임 시작하기

원하는 플레이어가 모두 접속하면 키보드에서 **S**를 누르세요.  
5초 카운트다운이 시작된 뒤 퀴즈가 자동으로 시작됩니다.

---

## 퀴즈 진행 방식

- 각 문제는 문제 텍스트, 네 개의 선택지, 이미지와 함께 게임 화면에 나타납니다.
- 플레이어는 휴대폰에서 같은 문제를 보고 네 개의 선택지 중 하나를 탭합니다.
- 플레이어에게는 답할 시간이 **30초** 주어집니다. 타이머는 화면 하단에 흰색 막대로 표시됩니다.
- 모든 플레이어가 답하면(또는 시간이 다 되면) 화면에 정답이 공개되고, 답이 어떻게 분포되었는지 보여 주는 원그래프가 표시됩니다.
- 플레이어는 휴대폰에서 정답 여부와 획득한 점수를 확인합니다. 빨리 맞힐수록 더 많은 점수를 받습니다.
- 모든 문제가 끝나면 각 플레이어의 점수가 가장 낮은 점수부터 가장 높은 점수 순으로 하나씩 공개되고, 마지막에 우승자가 발표됩니다.
- 최종 순위가 표시됩니다. 플레이어는 휴대폰에서도 자신의 점수와 순위를 볼 수 있습니다.

---

## 유용한 조작

화면 위로 커서를 움직이면 화면 하단에 **컨트롤 바**가 나타납니다. 컨트롤 바의 구성:

| 조작        | 기능                                                  |
| --------- | --------------------------------------------------- |
| 일시 정지 아이콘 | 퀴즈를 일시 정지합니다. 재생 아이콘을 클릭하면 다시 시작합니다 |
| 볼륨 슬라이더   | 왼쪽으로 끌면 퀴즈 소리가 모두 꺼집니다                              |
| 게임 코드     | 플레이어가 참가할 때 사용하는 코드                                 |

---

## 문제가 생겼을 때 해야 할 일

- **실수로 퀴즈를 닫았나요?** 퀴즈 URL을 다시 여세요. 이전 게임에 대해 묻는 팝업이 나타나면 **아니요**(또는 “계속”)를 클릭해 중단한 지점부터 이어 가세요.
- **플레이어가 연결이 끊겼나요?** 최대 플레이어 수에 아직 도달하지 않았다면 같은 코드로 다시 참가할 수 있습니다.
- **화면이 검게 변하거나 멈췄나요?** **F5**를 눌러 새로 고치거나 Chrome의 새로고침 아이콘을 클릭하세요.
