# 컨퍼런스 부스

이 튜토리얼에서는 컨퍼런스 부스에서 QuizWitz를 운영하는 방법을 알려 드립니다 - 방문객을 끌어모으고 잠재 고객 정보를 수집하는 쉽고 인터랙티브한 방법입니다!

![QuizWitz를 사용하는 Marvel 컨퍼런스 부스 사진](/images/photos/marvel.jpg)

---

## 📝 퀴즈 만들기

컨퍼런스 부스용 퀴즈를 만들 때는 일부 플레이어가 머무르며 여러 번 게임을 할 수 있다는 점을 염두에 두세요.  
매번 새로운 느낌을 주려면 문제를 넉넉히 준비하세요 - 무작위로 섞어 매 게임을 다르게 만들 수 있을 만큼 충분히 필요합니다.

**권장 구성:**

- 문제 15개를 라운드 3개로 나누기
- 다양성을 위해 최소 그 3배만큼 문제를 만드세요 - 많을수록 좋습니다!

### 🎲 단계별 퀴즈 만들기

1. 만들기 메뉴에서 **“퀴즈”를 선택**하고 퀴즈 이름을 정합니다. 올바른 언어를 설정합니다.
2. **라운드 3개를 추가**하고 이름을 정합니다(예: 라운드 1, 라운드 2, 라운드 3).
3. **라운드 설정**(톱니바퀴 아이콘)에서 \*\*“x개 문제만 표시”\*\*를 켜고 숫자를 5로 설정합니다.  
   \*\*“무작위 문제 순서”\*\*도 켜세요 - 그렇지 않으면 게임이 항상 처음 5개 문제를 고릅니다.  
   라운드마다 반복합니다.

![컨퍼런스 부스용 라운드 설정 스크린샷](/images/tutorials/conference/round_settings.png)

4. **각 라운드에 문제를 추가합니다.**  
   [문제를 직접 작성](../editor/005-writing-questions.md)하거나 가져오기 버튼으로 Excel에서 콘텐츠를 빠르게 추가할 수 있습니다.

:::tip
이미지와 동영상 클립을 많이 사용하세요 - 게임이 훨씬 더 재미있어집니다!
:::

---

### 🔀 무작위 선택의 작동 방식

퀴즈가 실행될 때마다 QuizWitz는 각 라운드에서 무작위로 문제 5개를 고릅니다. 시스템이 문제를 고르게 배분하므로 중복이 최소화됩니다.

---

## 🚀 퀴즈 실행하기

컨퍼런스 퀴즈를 가장 빠르게 실행하는 방법:

1. **퀴즈 플레이**를 클릭합니다.
2. **컨퍼런스 모드 시작**을 선택합니다.

이 모드에서는 플레이어가 휴대폰으로 게임 화면에 표시된 게임 링크에 접속합니다.  
모두 준비되면 부스 호스트가 Enter를 누릅니다 - 그러면 게임이 자동으로 진행됩니다.  
게임이 끝난 뒤 Enter를 누르면 다음 그룹을 위해 바로 접속 화면으로 돌아갑니다.

## ⚙️ 고급 게임 옵션

더 세밀하게 제어하고 싶으신가요?  
**고급 게임 옵션**을 선택하고 모드 선택기에서 **컨퍼런스 모드**를 고르세요.  
선택한 모든 옵션이 담긴 고유 링크를 받게 됩니다.

- **플레이어 이메일 요청:**  
  부스 방문객의 이메일을 수집하세요! 이 옵션을 켜면 **개인정보 처리방침 URL**도 꼭 설정하세요.
- 고급 옵션 링크로 게임을 실행하면 시작하기 전에 로그인하라는 메시지가 나타날 수 있습니다 - 콘텐츠와 라이선스를 확인하기 위한 것입니다.
