# 테마

:::warning
나만의 QuizWitz 테마를 만들면 가장 자유롭게 꾸밀 수 있지만, 복잡하고 시간이 많이 드는 작업입니다. 대부분의 경우, 쉽게 수정할 수 있도록 특별히 설계된 [Emerald 테마](011-emerald-theme.md)를 커스터마이즈하는 편이 훨씬 낫습니다.
:::

QuizWitz 테마는 **Adobe Animate**로 만듭니다. 시작점으로 사용할 [테마 템플릿](https://themes.quizwitz.com/empty/quizwitz-empty-theme.zip)을 다운로드할 수 있습니다. QuizWitz 테마 제작은 손이 많이 가는 작업이므로, Adobe Animate를 속속들이 아는 숙련된 디자이너에게 맡기는 것이 가장 좋습니다.

전문가에게 맡기고 싶으신가요? [support@catlab.be](mailto:support@catlab.be)로 이메일을 보내 주시면, 여러분의 디자인을 바로 사용할 수 있는 QuizWitz 테마로 만드는 견적을 보내 드립니다.

:::tip
그래픽 디자이너가 테마를 그리고 다른 사람이 Animate에서 조립하는 방식이 흔히 쓰입니다. [테마 디자인 가이드](012-theme-design-guide.md)에는 이 방식이 잘 작동하도록 디자이너가 전달해야 할 내용이 설명되어 있습니다.
:::

## 🧪 테마 테스트 도구

테마를 테스트할 준비가 되면 **디자인 폴더의 내용물을 zip으로 압축**하고( - 폴더 자체가 아니라, zip을 열었을 때 폴더 하나만이 아니라 파일들이 보여야 합니다 - ) [테마 테스터](https://themes.quizwitz.com/)에 업로드하세요. 테마가 게임에서 어떻게 보일지 실시간으로 미리 볼 수 있습니다.

테스트가 끝나면 zip 파일을 이메일로 보내 주세요. 계정에 연결해 드리면 퀴즈에서 테마를 선택하여 사용할 수 있습니다.

## 🖥️ 화면 개요

| 단계                                     | 게임 화면                                                                  | 플레이어 기기(태블릿/휴대폰)     |
| -------------------------------------- | ---------------------------------------------------------------------- | --------------------------------------- |
| 접속 화면                                  |                                                                        |                                         |
| 대기 화면                                  | 퀴즈 로고. 퀴즈마스터가 문제를 읽는 동안 표시됩니다.         | 플레이어에게 잘 들으라고 당부하는 인용문. |
| 게임 인트로                                 | 게임 시작 전 애니메이션.                                         | 대기 화면.                  |
| 라운드 인트로                                | 각 라운드 시작 전 애니메이션.                                      | 대기 화면.                  |
| 문제                                     |                                                                        |                                         |
| 첨부 파일                                  | 전체 화면 첨부 파일 보기( - 문제 또는 라운드 전후 - ). | 대기 화면.                  |
| 문제: 첨부 파일 없는 객관식       | 문제 + 객관식 선택지 4개.                                       | 객관식 답변 화면.              |
| 문제: 첨부 파일 있는 객관식       | 문제 + 객관식 선택지 4개 + 시각 첨부 파일.                            | 객관식 답변 화면.              |
| 문제: 첨부 파일 없는 주관식 문제    | 문제만 표시.                                                | 텍스트 입력란과 제출 버튼.         |
| 문제: 첨부 파일 있는 주관식 문제    | 문제 + 시각 첨부 파일.                                         | 텍스트 입력란과 제출 버튼.         |
| 활동: 선택된 팀              | 활동 이름.                                                 | 대기 화면 또는 “선택되었습니다” 화면.  |
| 피드백                                    |                                                                        |                                         |
| 문제 피드백: 객관식            | 문제, 정답 선택지, 답변 분포.                                     | 정답 / 오답 + 획득 점수.        |
| 문제 피드백: 주관식 문제         | 문제, 정답, 정답 비율(%).                   | 정답 / 오답 + 획득 점수.        |
| 문제 피드백: 주관식 문제 + 첨부 파일 | 문제, 정답 선택지, 답변 분포, 시각 첨부 파일.                           | 정답 / 오답 + 획득 점수.        |
| 문제 피드백: 객관식 + 첨부 파일    | 문제, 정답 선택지, 답변 분포, 시각 첨부 파일.                           | 정답 / 오답 + 획득 점수.        |
| 활동 피드백                                 | 활동에 선택된 팀.                                             | 대기 화면 또는 정답/오답 화면.      |
| 플레이어 순위                                |                                                                        |                                         |
| 라운드 아웃트로                               | 전체 플레이어 중 상위 10명.                                      | 현재 순위와 총점.              |
| 게임 아웃트로                                | 10위부터 1위까지 카운트다운한 뒤 최종 상위 10명.                         | 최종 순위와 총점.              |
