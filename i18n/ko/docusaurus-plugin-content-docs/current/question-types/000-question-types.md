# 문제 유형

QuizWitz는 다양한 문제 유형을 지원합니다. 각 유형에는 고유한 규칙과 게임 방식이 있습니다.
게임을 흥미롭고 몰입감 있게 유지하려면 여러 유형을 섞어 사용하는 것이 좋습니다.

일부 라운드 유형에서는 사용할 수 있는 문제 유형이 제한됩니다.

## 일반 문제 유형

가장 일반적인 문제 유형입니다. 이해하고 플레이하기 쉽습니다.

- [객관식](001-multiple-choice.md)(기본값)
- [순서 맞추기 문제](003-order-question.md)
- [이미지 맵 문제](004-image-map.md)
