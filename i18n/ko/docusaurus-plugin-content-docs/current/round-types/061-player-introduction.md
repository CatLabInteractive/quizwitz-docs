# 🙋‍♂️ 플레이어 소개

**플레이어 소개**는 게임 화면에 **모든 플레이어나 팀의 이름과 선택한 이모지**를 보여 주기만 하는 특별 이벤트입니다.

---

## 📝 작동 방식

- 퀴즈의 이 시점에서 각 참가자의 **이름**과 선택한 **이모지**가 게임 화면에 나타납니다.
- 주로 이벤트를 시작할 때, 휴식 후, 또는 결승 라운드 전에 참가자를 소개하거나 축하하는 데 사용합니다.

---

> 플레이어 소개는 분위기를 띄우고, 어색함을 깨고, 퀴즈 경험을 개인화하는 데 도움이 됩니다 - 특히 라이브 이벤트와 팀 기반 이벤트에서요!

---

다른 특별 이벤트 라운드는 [라운드 옵션](../editor/008-round-options.md)을 참고하세요.
