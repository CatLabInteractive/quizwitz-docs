# 라운드 유형

라운드 유형은 게임이 플레이어에게 문제를 보여 주는 방식과 플레이어가 점수를 얻는 방식에 영향을 줍니다.  
퀴즈에서는 화면 상단 가운데에 있는 **라운드 유형** 선택 필드에서 라운드 유형을 바꿀 수 있습니다.

- [연결고리](012-common-thread.md)

이 라운드 유형은 라운드가 끝날 때마다 “답안지를 제출하는” 방식을 재현합니다.
