# ❓ 멀티 문제

**멀티 문제** 라운드에서는 플레이어(또는 팀)가 여러 후보 중에서 답하고 싶은 문제를 자유롭게 고를 수 있습니다. 그래서 매번 다르게 플레이되고 전략적인 선택도 할 수 있습니다!

---

## 📝 작동 방식

- 각 “문제 그룹”마다 여러 개의 대체 문제가 제시됩니다.
- **각 플레이어(또는 팀)는 선택지 중에서 답할 문제 하나를 고릅니다**.
- 문제마다 점수, 난이도, 유형(객관식, 주관식 등)을 다르게 정할 수 있습니다.
- 플레이어는 자신이 고른 문제에만 답하고, 나머지 문제는 건너뜁니다.

---

## 🛠️ 에디터 설정

- 퀴즈 에디터에서 **문제 그룹**을 만드세요. 각 그룹에는 해당 차례의 대체 문제가 모두 들어 있습니다.
- 그룹 안의 각 문제에 **라벨** 필드를 설정하세요. 이 라벨은 플레이어가 고를 때 “제목”이나 힌트로 표시됩니다.
  - 라벨은 암호처럼(“A, B, C”), 테마별로(“동물”, “역사”), 또는 설명식으로(“쉬운 객관식”, “어려운 주관식”) 정할 수 있습니다.
- 같은 그룹 안에서 문제 유형과 점수를 자유롭게 섞을 수 있습니다.
- **시간:** 문제마다 타이머 배율을 다르게 설정할 수 있지만, 게임은 그룹의 모든 문제에 가장 높은 값을 적용합니다(누구도 서두르지 않도록).
- **첨부 파일:**
  - 모든 선택지의 _문제 전_ 첨부 파일은 플레이어가 선택하기 전에 한 화면에 모아서 표시됩니다.
  - _문제 중_ 첨부 파일 중 화면에 보이는 것은 표시되지 않지만, 오디오는 계속 재생됩니다.

---

## 💡 팁

- 전략성을 높이려면 쉬운 문제와 어려운 문제를 섞어서 제시하세요.
- 라벨을 창의적으로 활용하세요 - 수수께끼 같거나 재미있는 테마는 몰입도를 높여 줍니다.
- 점수가 높은 문제로 위험을 감수하는 플레이어에게 보상하세요.
