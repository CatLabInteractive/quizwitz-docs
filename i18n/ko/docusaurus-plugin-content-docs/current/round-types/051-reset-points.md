# 🔄 점수 초기화

**점수 초기화**는 모든 플레이어나 팀의 점수를 0으로 되돌리는 특별 이벤트(문제 라운드가 아님)입니다.  
모두를 같은 출발선에 세우거나, 긴장감을 더하거나, 퀴즈의 새로운 단계를 시작할 때 사용할 수 있습니다.

---

## 📝 작동 방식

- 이벤트가 실행되면 **모든 플레이어나 팀의 점수가 즉시 0이 됩니다**.
- 이전 순위나 성적과 관계없이 모든 참가자에게 적용됩니다.

---

> **점수 초기화**로 극적인 재시작이나 새로운 게임 단계를 만들거나, 큰 결승 라운드에서 모두에게 공평한 기회를 주세요!

---

게임 흐름을 구성하는 다른 방법은 [라운드 옵션](../editor/008-round-options.md)을 참고하세요.
