# 🎛️ 퀴즈마스터 앱 사용하기

퀴즈마스터는 QuizWitz Live 게임을 완전히 제어합니다. 가장 중요하게 알아 둘 점은 다음과 같습니다:

> 게임은 **클릭할 때만 진행됩니다** - 지시하기 전까지 게임 화면에서는 아무것도 움직이지 않습니다.

덕분에 진행 속도와 타이밍을 완전히 제어할 수 있지만, 그만큼 화면을 많이 탭해야 합니다. 앱이 어떻게 작동하는지 차근차근 살펴보겠습니다.

---

## 🔁 퀴즈 흐름

퀴즈 구성은 에디터에서 만든 대로 진행되지만, 대부분의 퀴즈는 다음 단계를 거칩니다:

---

### 🎬 라운드 소개

각 라운드가 시작되기 전에 라운드 소개 화면이 표시됩니다.

- **라운드 소개 애니메이션**을 재생할 시점은 직접 정합니다.
- \*\*‘시작’\*\*을 클릭하면 라운드가 시작되고 첫 번째 문제로 넘어갑니다.

---

### ❓ 문제 출제하기

퀴즈마스터 앱에서는 문제마다 전용 화면이 있습니다:

![퀴즈마스터 앱 - 문제 시작](/images/quizmaster-app-start-question.png)

다음이 표시됩니다:

- **문제 번호** - 예: `1.1`은 첫 번째 라운드의 첫 번째 문제를 뜻합니다
- **문제 유형** - 객관식 등, 관련 점수 옵션과 함께 표시
- **긴 버전의 문제** - 소리 내어 읽기 위한 문제
- **문제 정보** - 타이머 시간과 획득 가능한 점수 포함
- **짧은 문제** - 게임 화면에 표시되는 버전
- **문제 시작 버튼** - 누르는 즉시 타이머가 시작됩니다
- **가능한 답** - (객관식의 경우) 올바른 순서로 표시

문제는 다음 중 하나가 될 때까지 앱에 계속 표시됩니다:

- 모든 플레이어가 답했을 때
- 타이머가 끝났을 때

> 🔎 문제 유형과 라운드 유형에 대한 자세한 내용은 **퀴즈 제작자 가이드**를 확인하세요.

---

### ✅ 문제 피드백

문제가 끝나면 정답이 공개됩니다. 표시되는 내용은 문제 유형에 따라 다릅니다 - 이 예시는 객관식 결과 화면입니다:

![퀴즈마스터 앱 - 문제 피드백](/images/quizmaster-app-question-feedback.png)

포함 내용:

- **문제 번호**
- **짧은 문제 텍스트**
- **정답**
- **답변 분포** - 숫자와 백분율로 표시
- **긴 피드백** - 소리 내어 읽을 추가 정보
- **계속 버튼** - 다음 문제로 넘어갑니다
- **가장 빠른 답 100개** - 화면 하단에 표시

---

### 📊 라운드 마무리

라운드가 끝나면 지금까지의 순위를 보여 주는 **라운드 마무리** 화면이 표시됩니다.

![퀴즈마스터 앱 - 라운드 마무리](/images/quizmaster-app-round-outro.png)  
![QuizWitz - 라운드 마무리 게임 화면](/images/round-outro.png)

앱에서는:

- **상위 100명의 플레이어**가 표시되며, 스크롤해서 볼 수 있습니다
- 플레이어의 순위를 탭하면 게임 화면에서 해당 플레이어가 강조 표시됩니다
- 2라운드부터는 각 플레이어의 순위가 몇 계단 바뀌었는지도 표시됩니다:
  - **초록색** = 순위 상승
  - **빨간색** = 순위 하락
  - **흰색** = 변동 없음

마무리 화면에서 플레이어는 자신의 기기로 **자신의 순위**를 봅니다.

---

### 🏆 퀴즈의 끝

퀴즈가 끝나면 **우승자 발표 파티** 시간입니다 - 색종이가 흩날리고 플레이어 이모지가 화면을 가로질러 날아다닙니다.

![QuizWitz - 게임 마무리 게임 화면](/images/game-outro.png)

- 기본 설정에서는 **상위 12명의 플레이어**가 표시됩니다
- 표시할 플레이어 수는 **고급 게임 설정**에서 바꿀 수 있습니다

> 🎉 재미있는 팁: 플레이어가 고른 이모지가 화면에서 춤을 춥니다 - 웃는 똥을 골랐더라도요.

---

퀴즈마스터 앱으로 퀴즈를 진행하는 데 필요한 내용은 이것이 전부입니다. 이제 자신 있고 멋지게 이벤트를 이끌 준비가 모두 끝났습니다!
