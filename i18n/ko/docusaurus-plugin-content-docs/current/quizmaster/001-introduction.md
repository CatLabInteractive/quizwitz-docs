# 🎤 QuizWitz Live - 소개

## QuizWitz Live로 퀴즈 호스트하기

성공적인 QuizWitz Live 이벤트의 첫 번째 요소는 매력적인 퀴즈마스터, 즉 게임을 제어하고 분위기를 뜨겁게 유지하는 사람입니다. 퀴즈마스터는 퀴즈의 흐름을 이끌고, 문제를 소리 내어 읽고, 관객을 즐겁게 하는 특별한 활기를 더합니다.

이벤트를 완전히 제어하려면 QuizWitz Live 전용으로 설계된 **퀴즈마스터 앱**을 사용하세요.  
퀴즈 에디터에서 \*\*‘QuizWitz Live 시작’\*\*을 클릭하면 QuizWitz Live를 바로 실행할 수 있습니다.

> 💡 **참고:** 퀴즈마스터 앱은 **웹 앱**이므로 설치할 필요가 없습니다. 스마트 기기의 브라우저에서 [**quizwitz.tv**](https://quizwitz.tv)에 접속하기만 하면 됩니다.

---

## 🧰 준비물

매끄럽고 전문적인 퀴즈 진행을 위해 다음을 준비하세요:

- 게임 화면을 보여 주는 **대형 화면 또는 프로젝터** - 또는 모든 플레이어가 볼 수 있는 **라이브 스트림**
- 퀴즈마스터가 게임을 제어하고 대본을 소리 내어 읽을 **태블릿 또는 노트북**
- (필요한 경우) 심사위원이 주관식 문제를 평가할 **노트북 또는 태블릿**
- 답을 제출할 **플레이어 또는 팀당 스마트 기기 1대**(예: 스마트폰 또는 태블릿)

> 퀴즈에 **주관식 문제**가 있다면 제출된 답을 검토할 심사위원이 필요합니다. 퀴즈마스터가 추가 기기로 이 역할을 맡을 수도 있지만, 퀴즈마스터가 진행에 집중할 수 있도록 전담 심사위원을 한 명 이상 두는 것을 권장합니다.
