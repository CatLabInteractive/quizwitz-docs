# 🧑‍⚖️ 심사위원 앱 - QuizWitz Live에서 주관식 답 검토하기

퀴즈에 **주관식 문제**가 있다면 **심사위원 앱**으로 답을 직접 검토하고 채점해야 합니다.

---

## 🗂️ 심사위원 앱 사용하기

심사위원 앱은 심사위원이 답을 평가하고 점수를 관리하는 별도의 화면입니다.

심사위원 앱을 여는 방법:

1. 퀴즈가 시작되면 **심사위원 코드**가 생성됩니다.
2. 별도의 기기에서 [**quizwitz.tv**](https://quizwitz.tv)에 접속합니다
3. **심사위원 코드**를 입력해 앱에 접속합니다

> 💡 심사위원 앱은 어떤 브라우저에서도 열 수 있습니다 - 웹 앱이므로 설치가 필요 없습니다.

접속하면 심사위원 앱에서 여러 유용한 도구를 사용할 수 있습니다:

- **문제 심사** - 문제가 끝나면 주관식 문제의 결과가 나타납니다.
  - 게임은 심사위원이 끝낼 때까지 **기다리지 않습니다** - **라운드의 마지막 문제**이거나 퀴즈 설정에서 다르게 정한 경우는 예외입니다.
  - 심사가 끝나면 결과는 **다음 문제 뒤에** 표시됩니다.

- **점수 편집** - 플레이어나 팀별로 점수를 직접 주거나 회수합니다.

- **게임 제어** - 필요하면 문제 타이머를 조정하거나 스트리밍 지연을 추가합니다.
  > 라이브 스트림 지연 설정은 [**Twitch에서 QuizWitz Live 퀴즈를 호스트하는 방법**](../tutorials/040-livestreaming.md)을 참고하세요

- **보고서** - 결과와 플레이어의 답이 담긴 전체 게임 보고서를 생성합니다.

![대기 상태의 심사위원 앱 스크린샷](/images/jury-app-waiting.png)

---

## ✅ 주관식 문제 심사하기

주관식 문제가 끝날 때마다 심사위원 앱에 제출된 모든 답이 표시됩니다. 심사위원은 다음을 해야 합니다:

1. 각 답을 꼼꼼히 검토합니다
2. **인정할 수 있는** 답 옆의 확인란을 체크합니다
3. \*\*‘확인’\*\*을 클릭해 결과를 확정합니다

![심사 상태의 심사위원 앱 스크린샷](/images/jury-app-judging.png)

QuizWitz는 **정확히 일치하는 답을 자동으로 감지**해 정답으로 처리합니다. 심사위원이 검토할 대상은 다음과 같습니다:

- 부분적인 답이나 다른 형태의 답
- 발음이 비슷한 답
- 흔한 철자 변형

> 🎙️ QuizWitz는 발음이 비슷한 답도 인식하도록 설계되었지만, 최종 결정은 언제나 심사위원의 몫입니다.

---

심사위원 앱으로 주관식 답을 공정하게 평가하고, 점수를 조정하고, 모든 플레이어에게 균형 잡힌 퀴즈 경험을 제공할 수 있습니다.
