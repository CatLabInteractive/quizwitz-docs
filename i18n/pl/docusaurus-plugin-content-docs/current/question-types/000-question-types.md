# Typy pytań

QuizWitz obsługuje różne typy pytań. Każdy typ ma własne zasady i mechanikę rozgrywki.
Zalecamy łączenie różnych typów, aby gra była ciekawa i wciągająca.

Pamiętaj, że niektóre typy rund ograniczają typy pytań, których możesz używać.
