# प्रश्नों के प्रकार

QuizWitz अलग-अलग प्रश्न प्रकारों को सपोर्ट करता है। हर प्रकार के अपने नियम और गेमप्ले मैकेनिक्स होते हैं।
गेम को दिलचस्प और मज़ेदार बनाए रखने के लिए हम अलग-अलग प्रकारों का मिश्रण इस्तेमाल करने की सलाह देते हैं।

ध्यान दें कि कुछ राउंड प्रकार आपके इस्तेमाल किए जा सकने वाले प्रश्न प्रकारों को सीमित करते हैं।
