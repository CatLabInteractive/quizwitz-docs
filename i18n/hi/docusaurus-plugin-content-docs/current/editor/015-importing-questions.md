# 📥 प्रश्न इंपोर्ट करें

QuizWitz में किसी round में जल्दी से प्रश्न जोड़ने के दो तरीके हैं:

- **QuizWitz Library** से मौजूदा content इंपोर्ट करें
- **spreadsheet** से प्रश्नों की सूची paste करें

दोनों options किसी भी round के अंदर से उपलब्ध हैं।

---

## 📚 QuizWitz Library से इंपोर्ट करें

अपने या दूसरे creators द्वारा बनाए गए प्रश्न, rounds या quizzes खोजने और इंपोर्ट करने के लिए **QuizWitz Library** tab का इस्तेमाल करें।

1. वह round खोलें जिसमें आप content इंपोर्ट करना चाहते हैं
2. **QuizWitz Library** tab पर click करें
3. language, collection, type, category या tags जैसे filters का इस्तेमाल करें
4. एक या ज़्यादा entries चुनें
5. चुने गए content को अपने quiz में डालने के लिए **Add X items** पर click करें

![QuizWitz Library](/images/import/import-from-quizwitz.png)

> ✅ High-quality content को दोबारा इस्तेमाल करने या कई public Round-Abouts को मिलाकर बड़ा quiz बनाने के लिए यह तरीका इस्तेमाल करें।

---

## 📋 Spreadsheet से इंपोर्ट करें

एक साथ कई प्रश्न जल्दी बनाने के लिए **Import from spreadsheet** tab का इस्तेमाल करें।

1. एक round खोलें
2. **Import from spreadsheet** tab पर click करें
3. **tab-separated** values की rows paste करें (Excel, Google Sheets वगैरह से copy की गई)
4. **Import questions** पर click करें

![Import from spreadsheet](/images/import/import-from-spreadsheet.png)

---

### 🗂️ Paste करने का format

हर row में नीचे दिए गए columns इसी exact order में होने चाहिए:

1. **छोटा प्रश्न** — player screen पर दिखाया जाता है
2. **सही उत्तर**
3. **गलत उत्तर 1** (open questions के लिए खाली छोड़ें)
4. **गलत उत्तर 2**
5. **गलत उत्तर 3**
6. **छोटा feedback** — जवाब देने के बाद player screen पर दिखाया जाता है
7. **लंबा प्रश्न** _(optional)_ — quizmaster screen पर दिखाया जाता है
8. **लंबा feedback** _(optional)_ — quizmaster के ज़ोर से पढ़ने के लिए explanation

> 📌 आखिरी दो columns सिर्फ [QuizWitz Live](../quizmaster/001-introduction.md) में इस्तेमाल होते हैं, लेकिन इन्हें फिर भी शामिल करना ज़रूरी है (भले ही खाली छोड़ा हो)।

---

## ✅ इंपोर्ट करने के बाद

चाहे आप library से इंपोर्ट कर रहे हों या spreadsheet से:

- Formatting और clarity के लिए अपने प्रश्नों को review करें
- category, round type या attachments जैसे metadata update करें
- अपना quiz **save करना न भूलें**

📘 अपने प्रश्नों को और बेहतर बनाना चाहते हैं? [प्रश्न लिखने की guide](../editor/005-writing-questions.md) में आगे जारी रखें।
