# 🎖️ Запитання на найкращу відповідь

У типі **запитання на найкращу відповідь** гравці пишуть власні відповіді на відкрите запитання.  
Бали нараховує вручну квізмайстер, а якщо квізмайстра немає - гравці голосують за відповідь, яка їм найбільше сподобалася.

---

## 📝 Як це працює

- **Гравці відповідають:** кожен гравець вводить свою відповідь на відкрите запитання.
- **Нарахування балів:**
  - У **QuizWitz Live** (з квізмайстром) квізмайстер переглядає всі відповіді та нараховує бали найкращій (або найкращим).
  - В іграх без квізмайстра (Групова гра, Режим конференції) гравці голосують за відповідь, яку вважають найкращою. Бали отримує відповідь (або відповіді), що набрала найбільше голосів.

---

## 💡 Поради для запитань на найкращу відповідь

- Використовуй творчі відкриті запитання, які спонукають до оригінальних або смішних відповідей.
- У QuizWitz Live квізмайстер може нараховувати бали за креативність, точність або гумор.
- В іграх без квізмайстра голосування спонукає гравців читати відповіді одне одного й додає веселого соціального елемента.
