# Типи запитань

QuizWitz підтримує різні типи запитань. Кожен тип має власні правила та ігрову механіку.
Радимо поєднувати різні типи, щоб гра залишалася цікавою та захопливою.

Зверни увагу, що деякі типи раундів обмежують типи запитань, які можна використовувати.

## Звичайні типи запитань

Це найпоширеніші типи запитань. Їх легко зрозуміти й легко в них грати.

- [Вибір відповіді](001-multiple-choice.md) (за замовчуванням)
- [Запитання на впорядкування](003-order-question.md)
- [Запитання з картою зображення](004-image-map.md)
- [Запитання-сітка](008-grid-question.md)

## Відкриті запитання

У відкритих запитаннях гравці мають самі ввести відповідь.

- [Відкрите запитання](002-open-question.md)
- [Запитання-перелік](005-list-question.md)

## Особливі

Ці запитання роблять гру трохи менш чесною, але допомагають гарантувати, що переможець буде завжди.

- [Запитання-тайбрейк](006-tiebreaker-question.md)
- [Запитання на найкращу відповідь](007-best-answer-question.md)
