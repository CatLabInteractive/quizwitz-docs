# ⚙️ Розширені параметри

За допомогою параметрів рядка запиту можна налаштувати поведінку ігрового клієнта QuizWitz. Ці параметри можна додати до будь-якого посилання на гру за допомогою функції **Розширені налаштування гри**.

Приклад:

https://play.quizwitz.com/13305:qyHBEVVBqT?theme=emerald

📘 [Що таке рядки запиту?](https://en.wikipedia.org/wiki/Query_string)

---

## Доступні параметри:

| Параметр                 |       За замовчуванням       |           Приклад           | Пояснення                                                                                                                                                                                          |
| ------------------------ | :--------------------------: | :-------------------------: | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `language`               | (браузер) |              en             | Код мови ISO-639, який завантажується й використовується як базова мова                                                                                                                            |
| `theme`                  |            quizted           |           emerald           | Назва (або схвалена URL-адреса) теми оформлення, яку потрібно завантажити                                                                                                       |
| `reservation`            |               /              |            abcdef           | Токен бронювання, який потрібно використати (у живих іграх)                                                                                                                     |
| `remote`                 |  quizwitz.tv | quizwitz.tv | Сервер CatLab Remote, який потрібно використовувати                                                                                                                                                |
| `server`                 |               /              |              10             | ID сервера CatLab Remote, який потрібно використовувати (з автовиявленням)                                                                                                      |
| `publisher`              |               /              |           QuizWitz          | Назва видавця, який проводить гру. Використовується для налаштування вигляду                                                                                                       |
| `smileys`                |               1              |              0              | Встанови 0, щоб вимкнути смайлики в грі                                                                                                                                                            |
| `outroPlayers`           |              12              |          5,4,3,1,2          | Визначає кількість (число) АБО порядок гравців (перелік позицій через кому), яких буде оголошено під час завершення гри.                     |

| `translations`           |               1              |              0              | Встанови 0, щоб вимкнути завантаження перекладів квізу, який ти завантажуєш                                                                                                                        |
| `cycleTranslations`      |               0              |              1              | Встанови 1, щоб для кожного запитання по черзі показувати всі доступні мови квізу                                                                                                                  |
| `showLongQuestions`      |               0              |              1              | Встанови 1, щоб показувати «довге запитання» на екрані гри                                                                                                                                         |
| `forcePiecharts`         |               0              |              1              | Встанови 1, щоб завжди показувати весь розбір у вигляді кругових діаграм                                                                                                                           |
| `forceNoPiecharts`       |               0              |              1              | Встанови 1, щоб ніколи не групувати весь розбір у кругові діаграми.                                                                                                                |

| `monitors`               |               /              |            nl,fr            | Якщо задано, у живих іграх створюватимуться окремі коди для показу «монітора» цією конкретною мовою для квізмайстрів, які ведуть гру іншими мовами.                                |
| `allowLogin`             |               1              |              0              | Встанови 0, щоб заборонити користувачам входити в систему                                                                                                                                          |
| `tracker`                |               1              |              0              | Встанови 0, щоб вимкнути все відстеження. Звіт про квіз буде недоступний                                                                                                           |
| `random`                 |               0              |              1              | Встанови 1, щоб завантажити «випадковий квіз»                                                                                                                                                      |
| `delay`                  |               0              |            30000            | Задає кількість мілісекунд, на яку затримуватимуться всі дії гравців (для трансляцій)                                                                                           |
| `countdown`              |              10              |              60             | Задає кількість секунд «зворотного відліку» гри в режимі презентації.                                                                                                              |

| `beacon`                 |               /              |           my-beacn          | Задає токен маячка (beacon) CatLab Remote, за допомогою якого можна автоматично підключити застосунок квізмайстра.                                              |

| `showListenQuotes`       |               1              |              0              | Встанови 0, щоб вимкнути «кумедні» цитати із закликом «будь ласка, слухай».                                                                                                        |
| `shared`                 |               /              |  123:abcdef | Токен доступу до спільного елемента.                                                                                                                                               |
| `music`                  |               1              |              0              | Встанови 0, щоб вимкнути всю (ігрову) музику. Завантажене аудіо однаково відтворюватиметься.                                                    |
| `connectMusic`           |               1              |              0              | Встанови 0, щоб вимкнути (ігрову) музику, яка звучить на етапі «підключення».                                                                                   |
| `slideshowVideoInterval` |              300             |             300             | Якщо на етапі екрана підключення завантажено відео, цей параметр визначає кількість секунд між відтвореннями відео.                                                                |

| `departments`            |               1              |            A,B,C            | Встанови 0, щоб вимкнути завантаження відділів. Задай перелік назв через кому, щоб автоматично призначати всіх гравців, які підключаються, до випадкового відділу. |
| `showRankInDepartment`   |               1              |              0              | Встанови 0, щоб користувачі не бачили свого місця у своєму відділі.                                                                                                                |

| `preloadVideo`           |               0              |              1              | Встанови 1, щоб примусово попередньо завантажувати всі фрагменти відео.                                                                                                            |
| `n`                      |               /              |          `_prompt_`         | Задай (або запитай, встановивши значення `_prompt_`) назву групи гравців, яка грає в гру. Ця назва передається у звіт про квіз.                 |

## 💡 Поради щодо використання

- Кілька параметрів можна поєднувати за допомогою `&`
- Використовуй ці параметри у розділі **Розширені налаштування гри**, коли ділишся посиланнями або вбудовуєш їх
- Багато параметрів корисні для оптимізації трансляцій або багатомовних заходів
