# Типи раундів

Тип раунду впливає на те, як гра показує запитання гравцям, і на те, як гравці отримують бали.  
У квізах тип раунду можна змінити в полі вибору **Тип раунду** вгорі посередині екрана.

## 🍺 Традиційні

Для всіх, хто хоче організовувати традиційні паб-квізи, де гравці можуть змінювати відповіді до кінця раунду.  
Ці типи раундів імітують «здавання бланків» після кожного раунду.
