# ❓ Мультизапитання

Раунд **Мультизапитання** дає гравцям (або командам) свободу вибрати, на яке запитання відповідати, з кількох можливих. Завдяки цьому кожна гра унікальна, а гравці можуть ухвалювати стратегічні рішення!

---

## 📝 Як це працює

- Для кожної «групи запитань» пропонується кілька альтернативних запитань.
- **Кожен гравець (або команда) вибирає одне запитання** з доступних варіантів, щоб на нього відповісти.
- Кожне запитання може мати власну кількість балів, складність або тип (з вибором відповіді, відкрите тощо).
- Гравці відповідають лише на вибране запитання; решту для них пропускають.

---

## 🛠️ Налаштування в редакторі

- У редакторі квізів створи **групи запитань**. Кожна група містить усі альтернативні запитання для цього ходу.
- Для кожного запитання в групі заповни поле **Позначка**. Цю позначку гравці бачать як «назву» або підказку для свого вибору.
  - Мітки можуть бути загадковими («A, B, C»), тематичними («Тварини», «Історія») або описовими («Легкий вибір», «Складне відкрите»).
- У межах однієї групи можна поєднувати різні типи запитань і кількість балів.
- **Тривалість:** хоча для кожного запитання можна встановити інший множник таймера, гра використовує найбільше значення для всіх запитань у групі (щоб ніхто не поспішав).
- **Вкладення:**
  - Вкладення _перед запитанням_ з усіх варіантів об'єднуються в одному поданні, перш ніж гравці зроблять вибір.
  - Видимі вкладення _під час запитання_ не показуються, але аудіо все одно відтворюється.

---

## 💡 Поради

- Пропонуй поєднання легких і складних запитань для більшої стратегії.
- Використовуй мітки творчо - загадкові чи веселі теми можуть посилити залученість.
- Винагороджуй тих, хто ризикує, запитаннями з більшою кількістю балів.
