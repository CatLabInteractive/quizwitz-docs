# 📱 Мобільні браузери - Обмеження для проведення гри

QuizWitz оптимізовано для використання на **настільних комп'ютерах і ноутбуках**. Хоча технічно можна проводити ігри **QuizWitz Live** або в **режимі конференції** на планшеті чи смартфоні, ми **не радимо** використовувати пристрої **Android** або **iOS** для проведення гри.

> 🛑 Мобільні пристрої офіційно не підтримуються для проведення ігор. За можливості використовуй настільний комп'ютер або ноутбук.

---

## ⚠️ Якщо без мобільного пристрою не обійтися...

Якщо телефон або планшет - твій єдиний варіант, виконай ці кроки, щоб зменшити ризик технічних проблем:

### 🔋 Вимкни функції енергозбереження

- Переконайся, що **режими енергозбереження вимкнено**
- Збільш **час до автоматичного переходу в режим сну** на пристрої
- Деякі мобільні браузери можуть **оновлювати сторінку, коли пристрій засинає**, і це може несподівано завершити гру

### 🎞️ Перевір аудіо- та відеофрагменти

- Якщо у твоєму квізі є **аудіо або відео**, перевір їх заздалегідь
- Деякі пристрої можуть **погано справлятися з великими медіафайлами** або взагалі їх не відтворювати
- Будь особливо обережним зі **старими пристроями** або стандартними мобільними браузерами

---

## 🚫 Не рекомендується для живих заходів

Навіть з наведеними вище запобіжними заходами ми наполегливо **не радимо** використовувати мобільні пристрої для проведення важливих заходів або заходів із високими ставками.

Для найкращої продуктивності та стабільності:

- Використовуй **сучасний настільний комп'ютер або ноутбук**
- Запускай гру в **Chrome, Firefox** або **Edge**
- Не використовуй Safari на iOS ні для чого, крім гри як гравець

---

Для проведення гри головне - надійне обладнання, тож мобільні пристрої варто використовувати лише в крайньому разі.
