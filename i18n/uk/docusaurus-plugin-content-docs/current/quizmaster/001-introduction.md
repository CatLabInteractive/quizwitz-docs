# 🎤 QuizWitz Live - Вступ

## Проведення квізу з QuizWitz Live

Перший інгредієнт успішного заходу QuizWitz Live - захопливий квізмайстер, тобто людина, яка керує грою та підтримує високий рівень енергії. Квізмайстер веде квіз, читає запитання вголос і додає ту особливу іскру, яка розважає аудиторію.

Щоб повністю контролювати свій захід, використовуй **застосунок квізмайстра**, створений спеціально для QuizWitz Live.  
QuizWitz Live можна запустити безпосередньо з редактора квізів, натиснувши **«Запустити QuizWitz Live»**.

> 💡 **Примітка:** застосунок квізмайстра - це **вебзастосунок**, нічого встановлювати не потрібно. Просто відкрий [**quizwitz.tv**](https://quizwitz.tv) у браузері, щоб отримати доступ до нього на своєму смарт-пристрої.

## 🧰 Вимоги

Щоб квіз пройшов гладко й професійно, переконайся, що в тебе є:

- **Великий екран або проєктор**, на якому показано екран гри, або **трансляція**, доступна всім гравцям
- **Планшет або ноутбук** для квізмайстра, щоб керувати грою та читати сценарій уголос
- **Ноутбук або планшет** для журі (за потреби), щоб оцінювати відкриті запитання
- **Один смарт-пристрій на гравця або команду** (наприклад, смартфон або планшет), щоб надсилати відповіді

> Якщо у твоєму квізі є **відкриті запитання**, тобі знадобиться журі для перевірки відповідей. Квізмайстер може взяти цю роль на себе з додатковим пристроєм, але ми радимо призначити одного або кількох окремих членів журі, щоб квізмайстер міг зосередитися на веденні.
