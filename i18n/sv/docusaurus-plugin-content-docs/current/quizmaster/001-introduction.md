# 🎤 QuizWitz Live - Introduktion

## Arrangera ett quiz med QuizWitz Live

Den första ingrediensen för ett lyckat QuizWitz Live-evenemang är en engagerande quizmaster - någon som styr spelet och håller energin uppe. Quizmastern leder quizets flöde, läser upp frågorna och tillför den där extra gnistan som underhåller publiken.

För att ta full kontroll över ditt evenemang använder du **Quizmaster-appen**, som är utformad särskilt för QuizWitz Live.  
Du kan starta QuizWitz Live direkt från quizredigeraren genom att klicka på **’Starta QuizWitz Live’**.

> 💡 **Obs:** Quizmaster-appen är en **webbapp** - det finns inget att installera. Gå bara till [**quizwitz.tv**](https://quizwitz.tv) i webbläsaren för att öppna den på din smarta enhet.

---

## 🧰 Krav

För en smidig och professionell quizupplevelse, se till att du har:

- **En stor skärm eller projektor** som visar spelskärmen - eller en **livestream** som alla spelare kan se
- **En surfplatta eller bärbar dator** för quizmastern, för att styra spelet och läsa upp manuset
- **En bärbar dator eller surfplatta** för juryn (vid behov), för att bedöma öppna frågor
- **En smart enhet per spelare eller lag** (t.ex. smartphone eller surfplatta) för att skicka in svar

> Om ditt quiz innehåller **öppna frågor** behöver du en jury som granskar svaren. Quizmastern kan ta på sig den rollen med en extra enhet, men vi rekommenderar att du utser en eller flera särskilda jurymedlemmar så att quizmastern kan fokusera på att leda quizet.
