# Frågetyper

QuizWitz har stöd för olika frågetyper. Varje typ har sina egna regler och sin egen spelmekanik.
Vi föreslår att du blandar olika typer för att hålla spelet intressant och engagerande.

Observera att vissa rundtyper begränsar vilka frågetyper du kan använda.

## Vanliga frågetyper

Det här är de vanligaste frågetyperna. De är lätta att förstå och spela.

- [Flerval](001-multiple-choice.md) (standard)
- [Ordningsfråga](003-order-question.md)
- [Bildkartfråga](004-image-map.md)
- [Rutnätsfråga](008-grid-question.md)
