# 🏁 Utslagsfråga

Utslagsfrågan används för att avgöra vid lika poäng i slutet av ett quiz.  
Spelarna ombeds gissa ett tal (till exempel ”Hur många bönor finns det i burken?”). Den spelare vars svar ligger närmast det rätta värdet vinner vid lika poäng.

---

## 📝 Så fungerar det

- **Inga poäng delas ut:** Utslagsfrågan ger inga vanliga poäng.
- **Skuggpoäng:** I stället används ”skuggpoäng” som bara räknas när två eller fler spelare har samma totalpoäng.
- **Närmast vinner:** Spelaren med det svar som ligger närmast det rätta värdet får den högre placeringen vid lika poäng.

---

## 💡 Tips för utslagsfrågor

- **Fråga efter ett okänt tal:** Välj en fråga där svaret inte är allmänt känt och sannolikt inte gissas exakt.
- **Uppmuntra unika gissningar:** Se till att frågan har ett brett spann av möjliga svar, så att varje spelare sannolikt anger ett annat svar.
- **Använd bara vid lika poäng:** Skuggpoäng används bara för att avgöra vid lika poäng och påverkar inte spelets huvudrankning.

---

_Exempel på utslagsfrågor:_

- Hur många gelébönor finns det i burken som visas på skärmen?
- Vad är den sammanlagda längden (i meter) av alla floder i Belgien?
- Hur många tegelstenar användes för att bygga Empire State Building?
- Hur stor var publiken vid den allra första VM-finalen i fotboll?
