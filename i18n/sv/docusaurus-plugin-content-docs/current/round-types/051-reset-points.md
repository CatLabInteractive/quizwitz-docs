# 🔄 Nollställ poäng

**Nollställ poäng** är en speciell händelse (inte en frågerunda) som sätter alla spelares eller lags poäng till noll.  
Den kan användas för att jämna ut spelplanen, skapa spänning eller inleda nya faser i ditt quiz.

---

## 📝 Så fungerar det

- När händelsen utlöses **sätts varje spelares eller lags poäng direkt till 0**.
- Det gäller alla deltagare, oavsett tidigare rankning eller prestation.

---

> Använd **Nollställ poäng** för att skapa dramatiska omstarter, nya spelfaser eller för att ge alla en rättvis chans i en stor finalrunda!
