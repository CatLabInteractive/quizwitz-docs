# 🎤 QuizWitz Live - Εισαγωγή

## Φιλοξενία κουίζ με το QuizWitz Live

Το πρώτο συστατικό για μια επιτυχημένη εκδήλωση QuizWitz Live είναι ένας συναρπαστικός quizmaster - κάποιος που ελέγχει το παιχνίδι και κρατά την ενέργεια ψηλά. Ο quizmaster καθοδηγεί τη ροή του κουίζ, διαβάζει δυνατά τις ερωτήσεις και προσθέτει εκείνη την ξεχωριστή σπίθα που διασκεδάζει το κοινό.

Για να έχεις τον πλήρη έλεγχο της εκδήλωσής σου, χρησιμοποίησε την **Quizmaster App**, που έχει σχεδιαστεί ειδικά για το QuizWitz Live.  
Μπορείς να ξεκινήσεις το QuizWitz Live απευθείας από τον επεξεργαστή κουίζ κάνοντας κλικ στο **«Έναρξη QuizWitz Live»**.

> 💡 **Σημείωση:** Η Quizmaster App είναι μια **web εφαρμογή** - δεν χρειάζεται εγκατάσταση. Απλώς πήγαινε στο [**quizwitz.tv**](https://quizwitz.tv) στον browser σου για να την ανοίξεις στην έξυπνη συσκευή σου.

---

## 🧰 Απαιτήσεις

Για μια ομαλή και επαγγελματική εμπειρία κουίζ, βεβαιώσου ότι έχεις:

- **Μια μεγάλη οθόνη ή προβολέας** που δείχνει την οθόνη παιχνιδιού - ή μια **ζωντανή μετάδοση** προσβάσιμη σε όλους τους παίκτες
- **Ένα tablet ή laptop** για τον quizmaster, για να ελέγχει το παιχνίδι και να διαβάζει δυνατά το σενάριο
- **Ένα laptop ή tablet** για την κριτική επιτροπή (αν χρειάζεται), για την αξιολόγηση των ερωτήσεων ανοιχτής απάντησης
- **Μία έξυπνη συσκευή ανά παίκτη ή ομάδα** (π.χ. smartphone ή tablet) για την υποβολή απαντήσεων

> Αν το κουίζ σου περιλαμβάνει **ερωτήσεις ανοιχτής απάντησης**, θα χρειαστείς κριτική επιτροπή για να ελέγχει τις απαντήσεις. Αν και ο quizmaster μπορεί να αναλάβει αυτόν τον ρόλο με μια επιπλέον συσκευή, προτείνουμε να ορίσεις ένα ή περισσότερα αποκλειστικά μέλη κριτικής επιτροπής, ώστε ο quizmaster να επικεντρωθεί στην παρουσίαση.
