# 🧑‍⚖️ Εφαρμογή κριτικής επιτροπής - Έλεγχος ανοιχτών απαντήσεων στο QuizWitz Live

Αν το κουίζ σου περιλαμβάνει **ερωτήσεις ανοιχτής απάντησης**, θα χρειαστεί να χρησιμοποιήσεις την **εφαρμογή κριτικής επιτροπής** για να ελέγξεις και να βαθμολογήσεις χειροκίνητα τις απαντήσεις.

---

## 🗂️ Χρήση της εφαρμογής κριτικής επιτροπής

Η εφαρμογή κριτικής επιτροπής είναι μια ξεχωριστή διεπαφή που χρησιμοποιούν τα μέλη της κριτικής επιτροπής για να αξιολογούν απαντήσεις και να διαχειρίζονται τη βαθμολόγηση.

Για να ανοίξεις την εφαρμογή κριτικής επιτροπής:

1. Στην αρχή του κουίζ δημιουργείται ένας **κωδικός κριτικής επιτροπής**.
2. Σε μια ξεχωριστή συσκευή, πήγαινε στο [**quizwitz.tv**](https://quizwitz.tv)
3. Εισάγαγε τον **κωδικό κριτικής επιτροπής** για να αποκτήσεις πρόσβαση στην εφαρμογή

> 💡 Μπορείς να ανοίξεις την εφαρμογή κριτικής επιτροπής σε οποιονδήποτε browser - είναι web εφαρμογή, δεν χρειάζεται εγκατάσταση.

Μόλις μπεις, η εφαρμογή κριτικής επιτροπής προσφέρει αρκετά χρήσιμα εργαλεία:

- **Κρίση ερωτήσεων** - Τα αποτελέσματα των ανοιχτών ερωτήσεων εμφανίζονται μόλις ολοκληρωθεί μια ερώτηση.
  - Το παιχνίδι **δεν περιμένει** την κριτική επιτροπή να τελειώσει - εκτός αν πρόκειται για την **τελευταία ερώτηση του γύρου** ή οι ρυθμίσεις του κουίζ ορίζουν κάτι άλλο.
  - Μετά την κρίση, τα αποτελέσματα εμφανίζονται **μετά την επόμενη ερώτηση**.

- **Επεξεργασία σκορ** - Δώσε ή αφαίρεσε πόντους χειροκίνητα ανά παίκτη ή ομάδα.

- **Έλεγχος παιχνιδιού** - Προσάρμοσε τα χρονόμετρα των ερωτήσεων ή πρόσθεσε καθυστερήσεις μετάδοσης αν χρειάζεται.
  > Για τη ρύθμιση καθυστέρησης της ζωντανής μετάδοσης, δες [**πώς να φιλοξενήσεις ένα κουίζ QuizWitz Live στο Twitch**](../tutorials/040-livestreaming.md)

- **Αναφορά** - Δημιούργησε μια πλήρη αναφορά του παιχνιδιού με τα αποτελέσματα και τις απαντήσεις των παικτών.

## ✅ Κρίση ανοιχτών ερωτήσεων

Μετά από κάθε ανοιχτή ερώτηση, η εφαρμογή κριτικής επιτροπής εμφανίζει όλες τις απαντήσεις που υποβλήθηκαν. Τα μέλη της κριτικής επιτροπής πρέπει:

1. Να ελέγχουν προσεκτικά κάθε απάντηση
2. Να τσεκάρουν το πλαίσιο δίπλα σε κάθε **αποδεκτή** απάντηση
3. Να κάνουν κλικ στο **«Επιβεβαίωση»** για να κλειδώσουν τα αποτελέσματα

![Στιγμιότυπο της εφαρμογής κριτικής επιτροπής σε κατάσταση κρίσης](/images/jury-app-judging.png)

Το QuizWitz **εντοπίζει αυτόματα τις ακριβείς αντιστοιχίες** και τις σημειώνει ως σωστές. Τα μέλη της κριτικής επιτροπής είναι υπεύθυνα για τον έλεγχο:

- Μερικών ή εναλλακτικών απαντήσεων
- Φωνητικών αντιστοιχιών
- Συνηθισμένων ορθογραφικών παραλλαγών

> 🎙️ Το QuizWitz σχεδιάστηκε με γνώμονα τη φωνητική αντιστοίχιση - αλλά η τελική απόφαση ανήκει πάντα στους κριτές.

---

Με την εφαρμογή κριτικής επιτροπής μπορείς να αξιολογείς δίκαια τις ανοιχτές απαντήσεις, να προσαρμόζεις τα σκορ και να εξασφαλίζεις μια ισορροπημένη εμπειρία κουίζ για όλους τους παίκτες.
