# ⚙️ Προχωρημένες παράμετροι

Μπορείς να χρησιμοποιήσεις παραμέτρους query string για να προσαρμόσεις τη συμπεριφορά του προγράμματος παιχνιδιού του QuizWitz. Αυτές οι παράμετροι μπορούν να προστεθούν σε οποιονδήποτε σύνδεσμο παιχνιδιού μέσω της λειτουργίας **Προχωρημένες ρυθμίσεις παιχνιδιού**.

Παράδειγμα:

https://play.quizwitz.com/13305:qyHBEVVBqT?theme=emerald

📘 [Τι είναι τα query strings;](https://en.wikipedia.org/wiki/Query_string)

---

## Διαθέσιμες παράμετροι:

| Παράμετρος               |          Προεπιλογή          |          Παράδειγμα         | Επεξήγηση                                                                                                                                                                                                              |
| ------------------------ | :--------------------------: | :-------------------------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `language`               | (browser) |              en             | Κωδικός γλώσσας ISO-639 που φορτώνεται και χρησιμοποιείται ως βασική γλώσσα                                                                                                                                            |
| `theme`                  |            quizted           |           emerald           | Όνομα (ή εγκεκριμένο URL) του θέματος που θα φορτωθεί                                                                                                                                               |
| `reservation`            |               /              |            abcdef           | Token κράτησης που θα χρησιμοποιηθεί (σε live παιχνίδια)                                                                                                                                            |
| `remote`                 |  quizwitz.tv | quizwitz.tv | Διακομιστής CatLab Remote που θα χρησιμοποιηθεί                                                                                                                                                                        |
| `server`                 |               /              |              10             | Αναγνωριστικό διακομιστή CatLab Remote που θα χρησιμοποιηθεί (με αυτόματο εντοπισμό)                                                                                                                |
| `publisher`              |               /              |           QuizWitz          | Όνομα του προφίλ που φιλοξενεί το παιχνίδι. Χρησιμοποιείται για την προσαρμογή των προβολών                                                                                                            |
| `smileys`                |               1              |              0              | Όρισε 0 για να απενεργοποιήσεις τα smileys στο παιχνίδι                                                                                                                                                                |
| `outroPlayers`           |              12              |          5,4,3,1,2          | Ορίζει το πλήθος (αριθμό) Ή τη σειρά των παικτών (λίστα θέσεων χωρισμένων με κόμμα) που θα ανακοινωθούν κατά το κλείσιμο του παιχνιδιού.                         |
| `focusPositions`         |               /              |            50,100           | Ορίζει μια λίστα με επιπλέον θέσεις που θα εμφανίζονται στην Quizmaster App                                                                                                                                            |
| `translations`           |               1              |              0              | Όρισε 0 για να απενεργοποιήσεις τη φόρτωση μεταφράσεων του κουίζ που φορτώνεις                                                                                                                                         |
| `cycleTranslations`      |               0              |              1              | Όρισε 1 για εναλλαγή όλων των διαθέσιμων γλωσσών του κουίζ ανά ερώτηση                                                                                                                                                 |
| `showLongQuestions`      |               0              |              1              | Όρισε 1 για να εμφανίζεται η «μεγάλη ερώτηση» στην οθόνη παιχνιδιού                                                                                                                                                    |
| `forcePiecharts`         |               0              |              1              | Όρισε 1 για να εμφανίζεται πάντα όλη η ανατροφοδότηση σε διαγράμματα πίτας                                                                                                                                             |
| `forceNoPiecharts`       |               0              |              1              | Όρισε 1 για να μην ομαδοποιείται ποτέ όλη η ανατροφοδότηση σε διαγράμματα πίτας.                                                                                                                       |
| `piechartPercentages`    |               0              |              1              | Όρισε 1 για να εμφανίζονται ποσοστά αντί για απόλυτες τιμές σε όλα τα διαγράμματα πίτας                                                                                                                                |
| `monitors`               |               /              |            nl,fr            | Αν οριστεί, στα live παιχνίδια δημιουργούνται ξεχωριστοί κωδικοί για την εμφάνιση ενός «μόνιτορ» σε αυτή τη συγκεκριμένη γλώσσα για quizmaster σε άλλες γλώσσες.                                       |
| `allowLogin`             |               1              |              0              | Όρισε 0 για να μην επιτρέπεται στους χρήστες να συνδεθούν                                                                                                                                                              |
| `tracker`                |               1              |              0              | Όρισε 0 για να απενεργοποιήσεις κάθε παρακολούθηση. Δεν θα είναι διαθέσιμη αναφορά κουίζ                                                                                                               |
| `random`                 |               0              |              1              | Όρισε 1 για να φορτωθεί ένα «τυχαίο κουίζ»                                                                                                                                                                             |
| `delay`                  |               0              |            30000            | Ορίζει πόσα χιλιοστά του δευτερολέπτου θα καθυστερεί κάθε αλληλεπίδραση των παικτών (για ζωντανές μεταδόσεις)                                                                                       |
| `countdown`              |              10              |              60             | Ορίζει πόσα δευτερόλεπτα θα κάνει «αντίστροφη μέτρηση» το παιχνίδι στη λειτουργία παρουσίασης.                                                                                                         |
| `autoCountdown`          |               0              |              1              | Όρισε 1 για να ξεκινά αυτόματα η αντίστροφη μέτρηση μετά τη σύνδεση του πρώτου παίκτη στη λειτουργία παρουσίασης.                                                                                      |
| `autoRestart`            |               0              |              1              | Όρισε 1 για να ξεκινά αυτόματα ξανά το παιχνίδι μόλις τελειώσει.                                                                                                                                       |
| `waitForPlayers`         |               0              |              1              | Όρισε 1 για να μην γίνεται αναμονή παικτών όταν είναι ενεργό το `autoCountdown`                                                                                                                                        |
| `askEmail`               |               1              |              0              | Όρισε 0 για να μη ζητείται η διεύθυνση email του χρήστη στη λειτουργία παρουσίασης.                                                                                                                    |
| `beacon`                 |               /              |           my-beacn          | Ορίζει ένα token beacon του CatLab Remote που μπορεί να χρησιμοποιηθεί για την αυτόματη σύνδεση της Quizmaster App.                                                                                    |
| `rounds`                 |               5              |              7              | Ορίζει πόσοι γύροι θα δημιουργηθούν σε ένα τυχαίο κουίζ.                                                                                                                                               |
| `questions`              |               7              |              7              | Ορίζει πόσες ερωτήσεις θα δημιουργηθούν για κάθε γύρο σε ένα τυχαίο κουίζ.                                                                                                                             |
| `showListenQuotes`       |               1              |              0              | Όρισε 0 για να απενεργοποιήσεις τα «αστεία» αποφθέγματα «ακούστε προσεκτικά».                                                                                                                          |
| `shared`                 |               /              |  123:abcdef | Το token πρόσβασης ενός κοινόχρηστου στοιχείου.                                                                                                                                                        |
| `music`                  |               1              |              0              | Όρισε 0 για να απενεργοποιήσεις όλη τη μουσική (του παιχνιδιού). Ο ήχος που έχεις ανεβάσει θα εξακολουθεί να παίζει.                                                |
| `connectMusic`           |               1              |              0              | Όρισε 0 για να απενεργοποιήσεις τη μουσική (του παιχνιδιού) που παίζει κατά τη φάση «σύνδεσης».                                                                                     |
| `slideshowVideoInterval` |              300             |             300             | Όταν ανεβαίνουν βίντεο στη φάση της οθόνης σύνδεσης, ορίζει πόσα δευτερόλεπτα μεσολαβούν ανάμεσα στις αναπαραγωγές των βίντεο.                                                                         |
| `slideshowImageInterval` |              20              |              60             | Όταν ανεβαίνουν εικόνες στη φάση της οθόνης σύνδεσης, ορίζει πόσα δευτερόλεπτα εμφανίζεται κάθε εικόνα.                                                                                                |
| `skipOnAllAnswered`      |               1              |              0              | Όρισε 0 για να παρακάμψεις τη ρύθμιση `skipOnAllAnswered` των στοιχείων                                                                                                                                                |
| `departments`            |               1              |            A,B,C            | Όρισε 0 για να απενεργοποιήσεις τη φόρτωση τμημάτων. Όρισε μια λίστα ονομάτων χωρισμένων με κόμμα για να αντιστοιχίζονται αυτόματα όλοι οι παίκτες που συνδέονται σε ένα τυχαίο τμήμα. |
| `showRankInDepartment`   |               1              |              0              | Όρισε 0 για να μη βλέπουν οι χρήστες τη θέση τους μέσα στο τμήμα τους.                                                                                                                                 |
| `showDepartmentRanking`  |               1              |              0              | Όρισε 0 για να μην εμφανίζεται η κατάταξη των τμημάτων ανάμεσα στους γύρους.                                                                                                                           |
| `preloadVideo`           |               0              |              1              | Όρισε 1 για να επιβάλεις την προφόρτωση όλων των τμημάτων βίντεο.                                                                                                                                      |
| `n`                      |               /              |          `_prompt_`         | Όρισε (ή ζήτησε, ορίζοντας την τιμή `_prompt_`) ένα όνομα για την ομάδα παικτών που παίζει το παιχνίδι. Αυτό το όνομα αποστέλλεται στην αναφορά του κουίζ.          |

## 💡 Συμβουλές χρήσης

- Μπορείς να συνδυάσεις πολλές παραμέτρους με `&`
- Χρησιμοποίησε αυτές τις επιλογές με τις **Προχωρημένες ρυθμίσεις παιχνιδιού** όταν κοινοποιείς ή ενσωματώνεις συνδέσμους
- Πολλές επιλογές είναι χρήσιμες για τη βελτιστοποίηση ζωντανών μεταδόσεων ή για πολύγλωσσες εκδηλώσεις
