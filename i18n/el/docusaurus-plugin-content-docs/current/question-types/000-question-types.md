# Τύποι ερωτήσεων

Το QuizWitz υποστηρίζει διάφορους τύπους ερωτήσεων. Κάθε τύπος έχει τους δικούς του κανόνες και μηχανισμούς παιχνιδιού.
Προτείνουμε να χρησιμοποιείς έναν συνδυασμό διαφορετικών τύπων ώστε το παιχνίδι να παραμένει ενδιαφέρον και συναρπαστικό.

Σημείωσε ότι ορισμένοι τύποι γύρων περιορίζουν τους τύπους ερωτήσεων που μπορείς να χρησιμοποιήσεις.

## Κανονικοί τύποι ερωτήσεων

Αυτοί είναι οι πιο συνηθισμένοι τύποι ερωτήσεων. Είναι εύκολοι στην κατανόηση και στο παιχνίδι.

- [Πολλαπλή επιλογή](001-multiple-choice.md) (προεπιλογή)
- [Ερώτηση ταξινόμησης](003-order-question.md)
- [Ερώτηση χάρτη εικόνας](004-image-map.md)
- [Ερώτηση πλέγματος](008-grid-question.md)
