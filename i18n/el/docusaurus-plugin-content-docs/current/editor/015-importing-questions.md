# 📥 Εισαγωγή ερωτήσεων

Υπάρχουν δύο τρόποι για να προσθέσεις γρήγορα ερωτήσεις σε έναν γύρο στο QuizWitz:

- Εισαγωγή υπάρχοντος περιεχομένου από τη **βιβλιοθήκη QuizWitz**
- Επικόλληση μιας λίστας ερωτήσεων από ένα **υπολογιστικό φύλλο**

Και οι δύο επιλογές είναι διαθέσιμες μέσα από οποιονδήποτε γύρο.

---

## 📚 Εισαγωγή από τη βιβλιοθήκη QuizWitz

Χρησιμοποίησε την καρτέλα **Βιβλιοθήκη QuizWitz** για να αναζητήσεις και να εισαγάγεις ερωτήσεις, γύρους ή κουίζ που δημιούργησες εσύ ή άλλοι δημιουργοί.

1. Άνοιξε τον γύρο στον οποίο θέλεις να εισαγάγεις περιεχόμενο
2. Κάνε κλικ στην καρτέλα **Βιβλιοθήκη QuizWitz**
3. Χρησιμοποίησε φίλτρα όπως γλώσσα, συλλογή, τύπος, κατηγορία ή ετικέτες
4. Επίλεξε ένα ή περισσότερα στοιχεία
5. Κάνε κλικ στο **Προσθήκη X στοιχείων** για να εισαγάγεις το επιλεγμένο περιεχόμενο στο κουίζ σου

![Βιβλιοθήκη QuizWitz](/images/import/import-from-quizwitz.png)

> ✅ Χρησιμοποίησε αυτή τη μέθοδο για να επαναχρησιμοποιήσεις περιεχόμενο υψηλής ποιότητας ή για να συνδυάσεις πολλά δημόσια Round-About σε ένα μεγαλύτερο κουίζ.

---

## 📋 Εισαγωγή από υπολογιστικό φύλλο

Για να δημιουργήσεις γρήγορα πολλές ερωτήσεις μαζί, χρησιμοποίησε την καρτέλα **Εισαγωγή από υπολογιστικό φύλλο**.

1. Άνοιξε έναν γύρο
2. Κάνε κλικ στην καρτέλα **Εισαγωγή από υπολογιστικό φύλλο**
3. Επικόλλησε γραμμές με τιμές **χωρισμένες με tab** (αντιγραμμένες από Excel, Google Sheets κ.λπ.)
4. Κάνε κλικ στο **Εισαγωγή ερωτήσεων**

![Εισαγωγή από υπολογιστικό φύλλο](/images/import/import-from-spreadsheet.png)

---

### 🗂️ Μορφή για επικόλληση

Κάθε γραμμή πρέπει να περιέχει τις παρακάτω στήλες ακριβώς με αυτή τη σειρά:

1. **Σύντομη ερώτηση** - Εμφανίζεται στην οθόνη του παίκτη
2. **Σωστή απάντηση**
3. **Λάθος απάντηση 1** (άφησέ το κενό για ανοιχτές ερωτήσεις)
4. **Λάθος απάντηση 2**
5. **Λάθος απάντηση 3**
6. **Σύντομη ανατροφοδότηση** - Εμφανίζεται στην οθόνη του παίκτη μετά την απάντηση
7. **Μεγάλη ερώτηση** _(προαιρετικό)_ - Εμφανίζεται στην οθόνη του quizmaster
8. **Αναλυτική ανατροφοδότηση** _(προαιρετικό)_ - Επεξήγηση που διαβάζει δυνατά ο quizmaster

> 📌 Οι δύο τελευταίες στήλες χρησιμοποιούνται μόνο στο [QuizWitz Live](../quizmaster/001-introduction.md), αλλά πρέπει να συμπεριληφθούν οπωσδήποτε (ακόμη κι αν μείνουν κενές).

---

## ✅ Μετά την εισαγωγή

Είτε κάνεις εισαγωγή από τη βιβλιοθήκη είτε από υπολογιστικό φύλλο:

- Έλεγξε τις ερωτήσεις σου για τη μορφοποίηση και τη σαφήνεια
- Ενημέρωσε τυχόν μεταδεδομένα όπως κατηγορία, τύπο γύρου ή συνημμένα
- Μην ξεχάσεις να **αποθηκεύσεις το κουίζ σου**

📘 Θέλεις να βελτιώσεις κι άλλο τις ερωτήσεις σου; Συνέχισε στον [οδηγό σύνταξης ερωτήσεων](../editor/005-writing-questions.md).
