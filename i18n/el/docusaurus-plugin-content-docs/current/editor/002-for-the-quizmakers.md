# 🛠️ Οδηγός δημιουργού κουίζ

Καλώς ήρθες στον οδηγό για δημιουργούς κουίζ!  
Στο QuizWitz μπορείς να φτιάχνεις και να οργανώνεις το δικό σου περιεχόμενο κουίζ - ή να συλλέγεις και να αναμιγνύεις περιεχόμενο που έφτιαξαν άλλοι.

---

## 🧩 Τι μπορείς να δημιουργήσεις;

Ως δημιουργός κουίζ, μπορείς να δουλέψεις με:

- **Round-About** - Μικρές θεματικές συλλογές ερωτήσεων που εμφανίζονται με τυχαία σειρά
- **Ολοκληρωμένα κουίζ** - Προσαρμοσμένα κουίζ που συνδυάζουν πολλά Round-About με συγκεκριμένη σειρά

Μπορείς επίσης να **συλλέγεις Round-About** που έχουν δημιουργήσει άλλα μέλη και να τα συμπεριλαμβάνεις στα δικά σου κουίζ.

---

> 💡 **Συμβουλή:**  
> Ένα **Round-About** είναι το μικρότερο δομικό στοιχείο στο QuizWitz. Είναι ένα σύντομο σύνολο ερωτήσεων για ένα συγκεκριμένο θέμα.  
> Τα Round-About μπορούν να δημοσιευτούν για να τα χρησιμοποιήσουν άλλοι ή να παραμείνουν ιδιωτικά μόνο για σένα.
>
> Ένα **Ολοκληρωμένο κουίζ** σού επιτρέπει να συνδυάσεις πολλούς γύρους, να ορίσεις τη σειρά και να καθορίσεις τη δική σου ροή και τους δικούς σου κανόνες. Ιδανικό για εκδηλώσεις ή μεγαλύτερες εμπειρίες κουίζ!

---

## 💎 Άδεια χρήσης Premium

Για να δημιουργήσεις και να δημοσιεύσεις **Ολοκληρωμένα κουίζ**, θα χρειαστείς [άδεια χρήσης Premium](https://www.quizwitz.com/pricing).  
Έτσι ξεκλειδώνεις τη δυνατότητα να συνδυάζεις Round-About, να ορίζεις προσαρμοσμένη σειρά και να χρησιμοποιείς προχωρημένες λειτουργίες.

Τα Round-About μπορούν πάντα να δημιουργούνται και να κοινοποιούνται δωρεάν!

Εξερεύνησε τον επεξεργαστή, δοκίμασε ένα πρότυπο ή δες τις επόμενες σελίδες αυτού του οδηγού για περισσότερες συμβουλές και έμπνευση.
