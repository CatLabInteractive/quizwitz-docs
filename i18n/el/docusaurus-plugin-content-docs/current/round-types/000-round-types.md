# Τύποι γύρων

Ο τύπος γύρου επηρεάζει τον τρόπο με τον οποίο το παιχνίδι δείχνει τις ερωτήσεις στους παίκτες - και το πώς κερδίζουν πόντους οι παίκτες.  
Στα κουίζ, μπορείς να αλλάξεις τον τύπο γύρου στο πεδίο επιλογής **Τύπος γύρου** στο πάνω μέρος, στη μέση της οθόνης.

## 🍺 Παραδοσιακός

Για όποιον θέλει να διοργανώσει παραδοσιακά pub quiz, όπου οι παίκτες μπορούν να αλλάζουν τις απαντήσεις τους μέχρι το τέλος του γύρου.  
Αυτοί οι τύποι γύρων προσομοιώνουν την «παράδοση των χαρτιών» μετά από κάθε γύρο.
