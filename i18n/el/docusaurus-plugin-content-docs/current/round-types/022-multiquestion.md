# ❓ Πολυερώτηση

Ο γύρος **Πολυερώτηση** δίνει στους παίκτες (ή τις ομάδες) την ελευθερία να διαλέξουν σε ποια ερώτηση θέλουν να απαντήσουν από ένα σύνολο επιλογών. Έτσι κάθε παρτίδα είναι μοναδική και υπάρχει χώρος για στρατηγικές επιλογές!

---

## 📝 Πώς λειτουργεί

- Για κάθε «ομάδα ερωτήσεων» παρουσιάζονται αρκετές εναλλακτικές ερωτήσεις.
- **Κάθε παίκτης (ή ομάδα) επιλέγει μία ερώτηση** από τις διαθέσιμες επιλογές για να απαντήσει.
- Κάθε ερώτηση μπορεί να έχει τη δική της αξία σε πόντους, δυσκολία ή τύπο (πολλαπλή επιλογή, ανοιχτή κ.λπ.).
- Οι παίκτες απαντούν μόνο στην ερώτηση που διάλεξαν· οι υπόλοιπες παραλείπονται για αυτούς.

---

## 🛠️ Ρύθμιση στον επεξεργαστή

- Στον επεξεργαστή κουίζ, δημιούργησε **ομάδες ερωτήσεων**. Κάθε ομάδα περιέχει όλες τις εναλλακτικές ερωτήσεις για εκείνον τον γύρο επιλογής.
- Για κάθε ερώτηση της ομάδας, συμπλήρωσε το πεδίο **Ετικέτα**. Αυτή η ετικέτα εμφανίζεται στους παίκτες ως «τίτλος» ή υπόδειξη για την επιλογή τους.
  - Οι ετικέτες μπορεί να είναι κρυπτικές («Α, Β, Γ»), θεματικές («Ζώα», «Ιστορία») ή περιγραφικές («Εύκολη πολλαπλή», «Δύσκολη ανοιχτή»).
- Μπορείς να συνδυάσεις τύπους ερωτήσεων και αξίες πόντων μέσα στην ίδια ομάδα.
- **Διάρκεια:** Παρόλο που μπορείς να ορίσεις διαφορετικό πολλαπλασιαστή χρονομέτρου ανά ερώτηση, το παιχνίδι χρησιμοποιεί την υψηλότερη τιμή για όλες τις ερωτήσεις της ομάδας (ώστε να μη βιάζεται κανείς).
- **Συνημμένα:**
  - Τα συνημμένα _Πριν από την ερώτηση_ όλων των επιλογών συνδυάζονται σε μία προβολή πριν κάνουν οι παίκτες την επιλογή τους.
  - Τα ορατά συνημμένα _Κατά τη διάρκεια της ερώτησης_ δεν εμφανίζονται, αλλά ο ήχος εξακολουθεί να παίζει.

---

## 💡 Συμβουλές

- Πρόσφερε έναν συνδυασμό εύκολων και δύσκολων ερωτήσεων για περισσότερη στρατηγική.
- Χρησιμοποίησε τις ετικέτες δημιουργικά - μυστήριο ή διασκεδαστικά θέματα μπορούν να αυξήσουν τη συμμετοχή.
- Επιβράβευσε όσους ρισκάρουν με ερωτήσεις που δίνουν περισσότερους πόντους.
