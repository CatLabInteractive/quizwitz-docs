# 🔄 Μηδενισμός πόντων

Ο **Μηδενισμός πόντων** είναι ένα ειδικό γεγονός (όχι γύρος ερωτήσεων) που επαναφέρει στο μηδέν το σκορ όλων των παικτών ή ομάδων.  
Μπορεί να χρησιμοποιηθεί για να εξισωθούν οι όροι, να προστεθεί αγωνία ή να ξεκινήσουν νέες φάσεις στο κουίζ σου.

---

## 📝 Πώς λειτουργεί

- Όταν ενεργοποιηθεί, το γεγονός **ορίζει αμέσως σε 0 το σκορ κάθε παίκτη ή ομάδας**.
- Αυτό ισχύει για όλους τους συμμετέχοντες, ανεξάρτητα από την προηγούμενη κατάταξη ή επίδοση.

---

> Χρησιμοποίησε τον γύρο **Μηδενισμός πόντων** για να δημιουργήσεις δραματικές επανεκκινήσεις, νέες φάσεις παιχνιδιού ή για να δώσεις σε όλους μια δίκαιη ευκαιρία σε έναν μεγάλο τελικό γύρο!

---
