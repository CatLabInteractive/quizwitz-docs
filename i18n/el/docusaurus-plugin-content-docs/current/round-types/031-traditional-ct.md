# 📝🧵 Παραδοσιακός - Κοινός παρονομαστής

Ένας γύρος **Παραδοσιακός - Κοινός παρονομαστής** λειτουργεί ακριβώς όπως ένας [παραδοσιακός γύρος](030-traditional.md), αλλά με μια ανατροπή:  
Στο τέλος του γύρου, η **τελευταία ερώτηση** («Ποιος ήταν ο κοινός παρονομαστής;») αξιολογείται και εμφανίζεται πρώτη. Έτσι ο quizmaster μπορεί να αναδείξει τον σύνδεσμο πριν αποκαλύψει τις υπόλοιπες απαντήσεις.

---

![Στιγμιότυπο του παραδοσιακού γύρου στην οθόνη του παίκτη](/images/round-modes/traditional-answer-screen.png)

---

## 📝 Πώς λειτουργεί

- Οι παίκτες μπορούν να αλλάζουν τις απαντήσεις τους σε όλες τις ερωτήσεις μέχρι να τελειώσει ο γύρος.
- Στο τέλος, η τελευταία ερώτηση (ο κοινός παρονομαστής) αποκαλύπτεται και εξηγείται πρώτη.
- Η ανατροφοδότηση όλων των άλλων ερωτήσεων εμφανίζεται μετά, ώστε ο quizmaster να αναπτύξει τον σύνδεσμο.
