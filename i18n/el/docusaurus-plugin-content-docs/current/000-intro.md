# 🎉 Πρώτα βήματα

## Καλώς ήρθες στο QuizWitz!

Το **QuizWitz** είναι μια κοινωνική πλατφόρμα κουίζ όπου μπορείς:

- Να παίζεις διασκεδαστικά κουίζ με φίλους ή μόνος σου
- Να φιλοξενείς επαγγελματικές εκδηλώσεις κουίζ με εργαλεία live
- Να δημιουργείς τα δικά σου κουίζ, γύρους, playlist και πολλά άλλα

Είτε είσαι εδώ για να χαλαρώσεις, να παρουσιάσεις ή να δημιουργήσεις - σε καλύπτουμε.

Αφιέρωσε λίγο χρόνο για να εξερευνήσεις τους διάφορους ρόλους και τα διαθέσιμα εργαλεία. Θα σου πάρει μόνο ένα λεπτό.

---

## 👥 Παίκτες και δημιουργοί

Αυτός ο οδηγός χωρίζεται σε ενότητες ανάλογα με το πώς χρησιμοποιείς το QuizWitz:

- [**Οδηγός παίκτη**](players/001-playing-quizwitz.md) - Μάθε πώς να συλλέγεις, να παίζεις και να απολαμβάνεις κουίζ
- [**Οδηγός δημιουργού κουίζ**](editor/002-for-the-quizmakers.md) - Φτιάξε τις δικές σου ερωτήσεις, γύρους και ολοκληρωμένα κουίζ
- [**Οδηγός quizmaster**](quizmaster/001-introduction.md) - Φιλοξένησε ένα live παιχνίδι με το QuizWitz Live

Εξερεύνησε τις ενότητες που ταιριάζουν στον ρόλο σου - ή όλες, αν είσαι περίεργος!
