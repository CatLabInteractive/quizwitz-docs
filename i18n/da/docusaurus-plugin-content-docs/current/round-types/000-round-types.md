# Rundetyper

Rundetypen påvirker, hvordan spillet viser spørgsmålene for spillerne - og hvordan spillerne optjener point.  
I quizzer kan du ændre rundetypen i valgfeltet **Rundetype** øverst på midten af skærmen.

- [Rød tråd](012-common-thread.md)
