# Ein Konferenz-Quiz ausführen

Dieser Leitfaden führt Sie durch alles, was Sie wissen müssen, um ein QuizWitz-Quiz an einem Konferenzstand oder einer Veranstaltung durchzuführen – vom Öffnen des Quiz-Links zur endgültigen Rangliste.

---

## Anforderungen

Bevor du beginnst, vergewissere dich, dass du hast:

- Eine stabile Internetverbindung
- Die Quiz-URL (vorab bereitgestellt)
- Ein Laptop, der mit dem Bildschirm verbunden ist, den die Spieler beobachten werden
- **Google Chrome** — Andere Browser wie Safari oder Edge funktionieren möglicherweise nicht korrekt

---

## Zum ersten Mal das Quiz öffnen

1. Öffnen Sie die Quiz-URL in Google Chrome.  
   Wenn es nicht automatisch in Chrome geöffnet wird, klicken Sie mit der rechten Maustaste auf den Link und wählen Sie **Öffnen mit → Google Chrome**.

2. Ein schwarzes Ladebildschirm zeigt einen Prozentsatz an. Dies dauert nur wenige Sekunden.

3. Nach dem Laden erscheint der Quiz-Bildschirm. Wenn Sie aufgefordert werden, sich anzumelden, klicken Sie auf **Anmelden** — ein zweiter Tab öffnet sich.
   - Klicken Sie auf der Anmeldeseite auf **Anmelden** und geben Sie die Ihnen zur Verfügung gestellten Anmeldedaten ein.
   - Nach dem Einloggen schließt der Tab automatisch und das Quiz wird geladen.

4. Wenn das Laden abgeschlossen ist, erscheint der Startbildschirm des Tests.

5. Bewegen Sie den Cursor über den Bildschirm, um die Kontrollleiste unten anzuzeigen.  
   Klicke auf das **Quadrat-Symbol** auf der rechten Seite, um den Vollbildmodus zu betreten.  
   Das Quiz ist nun bereit auf dem Hauptbildschirm zu spielen.

:::tip
Um den Vollbildmodus jederzeit zu beenden — zum Beispiel, um zu einem anderen Fenster zu wechseln — drücke **Esc**.
:::

---

## Test für eine andere Gruppe neu starten

Um nach einem abgeschlossenen Spiel wieder zu spielen, haben Sie einige Möglichkeiten:

- **Lade die Seite neu** — klicke auf das Neuladen-Symbol in der Chrome-Symbolleiste (du musst Esc zuerst drücken, um Vollbild zu beenden).
- **Drücke S** — nachdem das Quiz beendet ist, bringt dich das Drücken von **S** auf der Tastatur zurück zum Startbildschirm.

Wenn ein Pop-up erscheint, in dem du fragst, ob du ein neues Spiel starten möchtest, klicke **Ja, starte neues Spiel**.

Sobald das Quiz neu geladen ist, wird es sich an Ihren Login erinnern und direkt zum Willkommensbildschirm gehen. Vollbild erneut mit der Kontrollleiste eingeben.

---

## Spieler, die am Quiz teilnehmen

Spieler treten auf zwei Arten mit eigenen Smartphones bei:

- Navigiere zu **www.quizwitz.tv** im Browser
- Scanne den **QR-Code** auf dem Hauptbildschirm

Auf dem Beitrittsbildschirm, Spieler:

1. Geben Sie den **8-stelligen Code** ein, der auf dem Hauptbildschirm angezeigt wird.
2. Geben Sie ihren **Namen und E-Mail-Adresse ein**.
3. Überprüfe das **Privatsphären-Kontrollkästchen**.
4. Tippe **LADY**.

Sobald die Spieler beigetreten sind, sehen sie eine Wartemeldung auf ihrem Telefon. Der Hauptbildschirm zeigt, wie viele Spieler verbunden sind.

:::note
Spieler können jederzeit beitreten, solange die maximale Anzahl an Spielern nicht erreicht ist.
:::

---

## Starte das Spiel

Sobald die gewünschten Spieler verbunden sind, drücken Sie **S** auf der Tastatur.  
Ein 5-Sekunden-Countdown beginnt und dann startet das Quiz automatisch.

---

## Wie das Quiz läuft

- Jede Frage erscheint auf dem Hauptbildschirm mit dem Fragetext, vier Antwortmöglichkeiten und einem Bild.
- Spieler sehen die gleiche Frage auf ihrem Handy und tippen auf eine der vier Optionen.
- Spieler haben **30 Sekunden** um zu antworten. Der Timer wird als weiße Leiste am unteren Bildschirmrand angezeigt.
- Sobald alle Spieler geantwortet haben (oder die Zeit abgelauft), die richtige Antwort wird auf dem Bildschirm als Tortendiagramm angezeigt, das zeigt, wie die Antworten verteilt wurden.
- Die Spieler sehen auf ihrem Handy, ob sie richtig beantwortet haben und wie viele Punkte sie gesammelt haben. Schnellere richtige Antworten verdienen mehr Punkte.
- Nach allen Fragen wird die Punktzahl jedes Spielers nach und nach aufgedeckt, von der niedrigsten bis zur höchsten und endet mit dem Gewinner.
- Eine letzte Rangliste wird angezeigt. Spieler können auch ihre Punktzahl und das Ranking auf ihrem Handy sehen.

---

## Nützliche Steuerelemente

Die **Kontrollleiste** erscheint am unteren Bildschirmrand, wenn Sie den Cursor über ihn bewegen. Er enthält:

| Steuerung        | Was es macht                                                |
| ---------------- | ----------------------------------------------------------- |
| Symbol pausieren | Pausiert das Quiz; klicke auf das Play-Icon um fortzufahren |
| Lautstärkeregler | Ziehen Sie nach links, um alle Quiz-Töne zu stummschalten   |
| Spielcode        | Die Code-Spieler verwenden um beizutreten                   |

---

## Was zu tun ist, wenn etwas schief geht

- **Quiz versehentlich geschlossen?** Öffne die Quiz-URL. Wenn das Pop-up nach einem vorherigen Spiel fragt, klicke auf **Nein** (oder "Weiter") um dort fortzufahren, wo du aufgehört hast.
- **Ein Spieler ist ausgelassen?** Er kann mit demselben Code wieder beitreten, solange die maximale Anzahl an Spielern noch nicht erreicht ist.
- **Bildschirm wurde schwarz oder eingefroren?** Versuche **F5** zu drücken, um neu zu laden, oder klicke auf das Neuladen-Symbol in Chrome.
