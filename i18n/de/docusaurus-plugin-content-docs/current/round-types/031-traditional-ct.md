# Thread: Traditionell - Gemeinsamer Thread

Eine **Traditionelle - Gemeinsame Thread** Runde funktioniert wie eine [traditionelle Runde](030-traditional.md), aber mit einer Drehung:  
Am Ende der Runde ist die **letzte Frage** („Was war der gemeinsame Thread?“) zuerst ausgewertet und angezeigt. Dadurch kann der Quizmaster die Verbindung hervorheben, bevor die anderen Antworten gezeigt werden.

---

![Screenshot der traditionellen Runde im Spielbildschirm](/images/round-modes/traditional-answer-screen.png)

---

## 📝 So funktioniert es

- Spieler können ihre Antworten auf alle Fragen ändern, bis die Runde endet.
- Am Ende wird die letzte Frage (der gemeinsame Faden) zuerst enthüllt und erklärt.
- Alle anderen Feedbacks zu den Fragen werden danach gezeigt, so dass der Quizmaster die Verbindung erläutern kann.
