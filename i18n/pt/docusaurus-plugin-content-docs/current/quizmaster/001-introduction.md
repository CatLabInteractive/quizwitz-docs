# 🎤 QuizWitz Live - Introduction

## Apresentar um quiz com QuizWitz Live

The first ingredient for a successful QuizWitz Live event is an engaging quizmaster - someone who controls the game and keeps the energy high. O quizmaster conduz o ritmo do quiz, lê as perguntas em voz alta e dá aquele toque extra para entreter o público.

Para ter controlo total do teu evento, usa a **App do Quizmaster**, criada especialmente para QuizWitz Live.  
Podes iniciar o QuizWitz Live diretamente pelo editor de quiz clicando em 'Iniciar QuizWitz Live'.

> 💡 **Note:** The Quizmaster App is a **web app** - there's nothing to install. Basta acederes a [**quizwitz.tv**](https://quizwitz.tv) no teu navegador para o usares no teu smart device.

---

## 🧰 Requisitos

Para garantir uma experiência de quiz tranquila e profissional, certifica-te de que tens:

- **A large screen or projector** showing the game screen - or a **livestream** accessible to all players
- **Um tablet ou notebook** para o quizmaster controlar o jogo e ler o roteiro em voz alta
- **Um notebook ou tablet** para o júri (se necessário) avaliar perguntas de resposta aberta
- **Um smart device por jogador ou equipa** (por exemplo, smartphone ou tablet) para enviar respostas

> Se o teu quiz incluir **perguntas de resposta aberta**, vais precisar de um júri para rever os envios. Embora o quizmaster possa assumir esse papel com um dispositivo extra, recomendamos designar um ou mais membros dedicados do júri para que o quizmaster possa se concentrar na apresentação.
