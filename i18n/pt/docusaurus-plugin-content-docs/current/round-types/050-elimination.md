# 🚫 Eliminação

**Eliminação** é um evento especial que remove automaticamente jogadores ou equipas do jogo com base na classificação ou pontuação atual deles.  
É uma ferramenta útil para torneios, playoffs ou para adicionar reviravoltas dramáticas em eventos ao vivo!

---

## 📝 Como funciona

- Quando acionado, o evento de eliminação avalia as classificações dos jogadores e **expulsa jogadores ou equipas** de acordo com a regra escolhida por ti.
- Eliminação não é um tipo de ronda com perguntas, mas sim um filtro automático entre rondas.

---

## ⚙️ Critérios de eliminação

Podes configurar o evento de eliminação para:

- **Expulsar jogadores com classificação mais baixa** até que reste um número especificado de jogadores
- **Expulsar jogadores com classificação mais alta** até que reste um número especificado de jogadores
- **Expulsar os com classificação mais baixa** (um número definido de) jogadores
- **Expulsar os com classificação mais alta** (um número definido de) jogadores

O número de jogadores a manter (ou expulsar) pode ser definido como um número exato ou como uma percentagem de todos os participantes.

---

> Eventos de eliminação são perfeitos para formatos de mata-mata, para reduzir o campo entre rondas de quiz ou para criar momentos tensos de "morte súbita" no teu jogo!
