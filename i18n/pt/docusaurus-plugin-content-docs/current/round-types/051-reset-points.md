# 🔄 Redefinir pontos

**Repor pontos** é um evento especial (não uma ronda de perguntas) que define a pontuação de todos os jogadores ou equipas de volta para zero.  
Isto pode ser usado para equilibrar o jogo, adicionar suspense ou introduzir novas fases no teu quiz.

---

## 📝 Como funciona

- Quando acionado, o evento **define instantaneamente a pontuação de cada jogador ou equipa como 0**.
- Isso se aplica a todos os participantes, independentemente da classificação ou desempenho anteriores.

---

> Usa **Repor pontos** para criar reinícios dramáticos, novas fases de jogo ou para dar a todos uma oportunidade justa numa grande ronda final!
