# Stand de conferência

This tutorial will show you how to run QuizWitz at your conference booth - an easy, interactive way to attract visitors and gather leads!

![Uma foto de um stand de conferência da Marvel usando o QuizWitz](/images/photos/marvel.jpg)

---

## 📝 Criar o quiz

Ao criares um quiz para um stand de conferência, lembra-te de que alguns jogadores podem ficar para vários jogos.  
To keep things fresh, make sure you have plenty of questions - enough to randomize and make each playthrough unique.

**Configuração recomendada:**

- 15 perguntas divididas em 3 rondas
- Create at least 3× that many questions for variety - more is better!

### 🎲 Criação do quiz passo a passo

1. **Escolhe “Quiz”** no menu Criar e dá um nome ao teu quiz. Define o idioma correto.
2. **Adiciona 3 rondas** e dá-lhes nomes (por exemplo: Ronda 1, Ronda 2, Ronda 3).
3. Nas **Definições da ronda** (ícone de engrenagem), ativa **“Mostrar apenas x perguntas”** e define o número como 5.  
   Also enable **“Random question order”** - otherwise the game will always pick the first 5 questions.  
   Repete para cada ronda.

![Captura de ecrã das definições da ronda para um stand de conferência](/images/tutorials/conference/round_settings.png)

4. **Adiciona perguntas a cada ronda.**  
   Podes [escrever perguntas](../editor/005-writing-questions.md) ou usar o botão Importar para adicionar rapidamente conteúdo do Excel.

:::tip
Use lots of images and video clips - they make the game much more entertaining!
:::

---

### 🔀 Como funciona a seleção aleatória

Sempre que o quiz é executado, o QuizWitz vai selecionar 5 perguntas aleatórias de cada ronda. O sistema vai distribuir as perguntas de forma justa para minimizar repetições.

---

## 🚀 Iniciar o quiz

A forma mais rápida de iniciar o teu quiz de conferência:

1. Clica em **Jogar quiz**.
2. Seleciona o **modo de conferência**.

Neste modo, os jogadores usam os telemóveis deles para se ligar ao link do jogo no ecrã do jogo.  
When everyone is ready, the booth host presses Enter - and the game runs automatically.  
Depois de o jogo terminar, ao premir Enter voltas diretamente ao ecrã de ligação para o próximo grupo.

---

## ⚙️ Opções avançadas do jogo

Queres mais controlo?  
Escolhe **Opções avançadas do jogo** e seleciona **Modo de conferência** no seletor de modo.  
Vais receber um link único com todas as opções que escolheste.

- **Pedir o email dos jogadores:**  
  Recolhe emails de visitantes para o teu stand! Se ativares isto, certifica-te também de definir o teu **URL da Política de Privacidade**.
- When launching a game via the advanced options link, you may be prompted to log in before starting - this checks your content and licenses.
