# ⚙️ Parâmetros avançados

Podes usar parâmetros de query string para personalizar como o cliente de jogo do QuizWitz se comporta. Estes parâmetros podem ser adicionados a qualquer link de jogo usando a funcionalidade **Configurações avançadas do jogo**.

Exemplo:

https://play.quizwitz.com/13305:qyHBEVVBqT?theme=emerald

📘 [O que são query strings?](https://en.wikipedia.org/wiki/Query_string)

---

## Parâmetros disponíveis:

| Parâmetro                |             Padrão             |           Exemplo           | Explicação                                                                                                                                                                                                                                         |
| ------------------------ | :----------------------------: | :-------------------------: | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `language`               | (navegador) |              en             | Código de idioma ISO-639 para carregar e usar como idioma base                                                                                                                                                                                     |
| `theme`                  |             quizted            |           emerald           | Nome (ou URL aprovado) do tema a ser carregado                                                                                                                                                                                  |
| `reservation`            |                /               |            abcdef           | Token de reserva a usar (em jogos ao vivo)                                                                                                                                                                                      |
| `remote`                 |   quizwitz.tv  | quizwitz.tv | Servidor CatLab Remote a usar                                                                                                                                                                                                                      |
| `server`                 |                /               |              10             | ID do servidor CatLab Remote a usar (com descoberta automática)                                                                                                                                                                 |
| `publisher`              |                /               |           QuizWitz          | Nome do perfil que está a organizar o jogo. Isto é usado para personalizar visualizações                                                                                                                                           |
| `smileys`                |                1               |              0              | Define como 0 para desativar smileys no jogo                                                                                                                                                                                                       |
| `outroPlayers`           |               12               |          5,4,3,1,2          | Define a quantidade (número) OU a ordem dos jogadores (lista de posições separadas por vírgula) que será anunciada durante o encerramento do jogo.                                           |
| `focusPositions`         |                /               |            50,100           | Define uma lista de posições adicionais que será exibida no app Quizmaster                                                                                                                                                                         |
| `translations`           |                1               |              0              | Define como 0 para desativar o carregamento das traduções do quiz que estás a carregar                                                                                                                                                             |
| `cycleTranslations`      |                0               |              1              | Define como 1 para alternar entre todos os idiomas disponíveis do quiz a cada pergunta                                                                                                                                                             |
| `showLongQuestions`      |                0               |              1              | Define como 1 para mostrar a 'pergunta longa' no ecrã do jogo                                                                                                                                                                                      |
| `forcePiecharts`         |                0               |              1              | Define como 1 para sempre mostrar todo o feedback em gráficos circulares                                                                                                                                                                           |
| `forceNoPiecharts`       |                0               |              1              | Define como 1 para nunca agrupar todo o feedback em gráficos circulares.                                                                                                                                                           |
| `piechartPercentages`    |                0               |              1              | Define como 1 para mostrar percentagens em vez de valores absolutos em todos os gráficos circulares                                                                                                                                                |
| `monitors`               |                /               |            nl,fr            | Se definido, em jogos ao vivo serão criados códigos separados para exibir um 'monitor' nesse idioma específico para quizmasters localizados.                                                                                       |
| `allowLogin`             |                1               |              0              | Define como 0 para não permitir que os utilizadores façam login                                                                                                                                                                                    |
| `tracker`                |                1               |              0              | Define como 0 para desativar todo o rastreamento. Nenhum relatório de quiz estará disponível                                                                                                                                       |
| `random`                 |                0               |              1              | Define como 1 para carregar um 'quiz aleatório'                                                                                                                                                                                                    |
| `delay`                  |                0               |            30000            | Define a quantidade de milissegundos de atraso para todas as interações dos jogadores (para transmissões ao vivo)                                                                                                               |
| `countdown`              |               10               |              60             | Define a quantidade de segundos que o jogo fará de 'contagem regressiva' no modo de apresentação.                                                                                                                                  |
| `autoCountdown`          |                0               |              1              | Define como 1 para iniciar automaticamente a contagem regressiva depois de o primeiro jogador entrar no modo de apresentação.                                                                                                      |
| `autoRestart`            |                0               |              1              | Define como 1 para reiniciar automaticamente o jogo depois de ele terminar.                                                                                                                                                        |
| `waitForPlayers`         |                0               |              1              | Define como 1 para não esperar por nenhum jogador quando `autoCountdown` estiver ativado                                                                                                                                                           |
| `askEmail`               |                1               |              0              | Define como 0 para não pedir o endereço de e-mail do utilizador no modo de apresentação.                                                                                                                                           |
| `beacon`                 |                /               |           my-beacn          | Define um sinalizador (beacon) CatLab Remote que pode ser usado para conectar automaticamente o app Quizmaster                                                                                                                  |
| `rounds`                 |                5               |              7              | Define a quantidade de rondas que serão geradas num quiz aleatório.                                                                                                                                                                |
| `questions`              |                7               |              7              | Define a quantidade de perguntas que serão geradas para cada ronda num quiz aleatório.                                                                                                                                             |
| `showListenQuotes`       |                1               |              0              | Define como 0 para desativar as citações 'engraçadas' de 'por favor, escute'.                                                                                                                                                      |
| `shared`                 |                /               |  123:abcdef | O token de acesso de uma entrada partilhada.                                                                                                                                                                                       |
| `music`                  |                1               |              0              | Define como 0 para desativar toda a música (do jogo). O áudio enviado ainda será reproduzido.                                                                                                   |
| `connectMusic`           |                1               |              0              | Define como 0 para desativar a música (do jogo) que toca durante a fase de 'ligação'.                                                                                                                           |
| `slideshowVideoInterval` |               300              |             300             | Quando vídeos são enviados na fase do ecrã de ligação, isso define a quantidade de segundos entre cada reprodução de vídeo.                                                                                                        |
| `slideshowImageInterval` |               20               |              60             | Quando imagens são enviadas na fase do ecrã de ligação, isso define a quantidade de segundos que cada imagem será exibida.                                                                                                         |
| `skipOnAllAnswered`      |                1               |              0              | Define como 0 para substituir as entradas `skipOnAllAnswered`                                                                                                                                                                                      |
| `departments`            |                1               |            A,B,C            | Define como 0 para desativar o carregamento de departamentos. Define como uma lista de nomes separados por vírgula para atribuir automaticamente todos os jogadores que se conectarem a um departamento aleatório. |
| `showRankInDepartment`   |                1               |              0              | Define como 0 para impedir que os utilizadores vejam a sua classificação dentro do departamento.                                                                                                                                   |
| `showDepartmentRanking`  |                1               |              0              | Define como 0 para desativar a exibição da classificação dos departamentos entre as rondas.                                                                                                                                        |
| `preloadVideo`           |                0               |              1              | Define como 1 para forçar o pré-carregamento de todos os fragmentos de vídeo.                                                                                                                                                      |
| `n`                      |                /               |          `_prompt_`         | Define (ou solicita definindo como `_prompt_`) um nome para o grupo de jogadores que está a jogar o jogo. Este nome é enviado para o relatório do quiz.                                         |

---

## 💡 Dicas de uso

- Vários parâmetros podem ser combinados usando `&`
- Use estas opções com **Configurações avançadas do jogo** ao compartilhar ou incorporar links
- Muitas opções são úteis para otimização de transmissões ao vivo ou eventos multilíngues
