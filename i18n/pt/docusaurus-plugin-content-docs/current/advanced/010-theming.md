# Temas

:::warning
Embora criar o seu próprio tema QuizWitz ofereça a maior flexibilidade, é um processo complexo e demorado. Na maioria dos casos, é muito melhor personalizar o nosso [tema Emerald](011-emerald-theme.md), que foi desenvolvido especificamente para ser fácil de adaptar.
:::

Os temas QuizWitz são criados usando o **Adobe Animate**. Você pode baixar um [modelo de tema](https://themes.quizwitz.com/empty/quizwitz-empty-theme.zip) para usar como ponto de partida. Tenha em mente que criar temas para o QuizWitz é um trabalho minucioso e fica melhor nas mãos de designers experientes que conhecem todos os detalhes do Adobe Animate.

Prefere deixar isso com os profissionais? Envie um e-mail para [support@catlab.be](mailto:support@catlab.be) e podemos preparar uma estimativa para transformar o seu design em um tema QuizWitz pronto para usar.

---

## 🧪 Ferramenta de teste de tema

Quando estiver tudo pronto para testar o seu tema, **compacte o conteúdo da sua pasta de design** ( — não a pasta em si; ao abrir o zip, você deve ver os seus arquivos, não apenas uma única pasta — ) e envie para o nosso [testador de temas](https://themes.quizwitz.com/). Isso te dá uma prévia ao vivo de como o seu tema vai aparecer no jogo.

Depois de testar, envie o arquivo zip por e-mail para nós e vamos vinculá-lo à sua conta para que você possa selecionar e usar o seu tema nos seus quizzes.

---

## 🏷️ Logo QuizWitz

Todos os designs personalizados devem incluir o logo QuizWitz.

## 🖥️ Visão geral das telas

| Etapa                                                          | Tela de jogo                                                                                                         | Dispositivo do jogador (tablet/celular)            |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Tela de conexão                                                |                                                                                                                      |                                                                       |
| Tela de espera                                                 | Logo do quiz. Exibido enquanto o testador está lendo a pergunta.                     | Uma frase incentivando o jogador a ouvir com atenção. |
| Introdução do jogo                                             | Animação antes do jogo.                                                                              | Tela de espera.                                       |
| Introdução da rodada                                           | Animação antes de cada rodada.                                                                       | Tela de espera.                                       |
| Perguntas                                                      |                                                                                                                      |                                                                       |
| Anexo                                                          | Visualização do anexo em tela cheia ( — antes/depois de perguntas ou rodadas — ). | Tela de espera.                                       |
| Pergunta: múltipla escolha sem anexo           | Pergunta + 4 opções de múltipla escolha.                                                             | Tela de resposta de múltipla escolha.                 |
| Pergunta: múltipla escolha com anexo           | Pergunta + 4 opções de múltipla escolha + um anexo visual.                                           | Tela de resposta de múltipla escolha.                 |
| Pergunta: pergunta aberta sem anexo            | Apenas a pergunta.                                                                                   | Entrada de texto e botão de enviar.                   |
| Pergunta: pergunta aberta com anexo            | A pergunta + um anexo visual.                                                                        | Entrada de texto e botão de enviar.                   |
| Atividade: equipes escolhidas                  | O nome de uma atividade.                                                                             | Tela de espera ou tela de "você foi selecionado".     |
| Comentários                                                    |                                                                                                                      |                                                                       |
| Feedback da pergunta: múltipla escolha         | A pergunta, as opções corretas e a distribuição das respostas.                                       | Correto / errado + pontos ganhos.                     |
| Feedback da pergunta: pergunta aberta          | A pergunta, as opções corretas e a % de respostas corretas.                                          | Correto / errado + pontos ganhos.                     |
| Feedback da pergunta: pergunta aberta + anexo  | A pergunta, as opções corretas, a distribuição das respostas e um anexo visual.                      | Correto / errado + pontos ganhos.                     |
| Feedback da pergunta: múltipla escolha + anexo | A pergunta, as opções corretas, a distribuição das respostas e um anexo visual.                      | Correto / errado + pontos ganhos.                     |
| Feedback da atividade                                          | As equipes selecionadas para uma atividade.                                                          | Tela de espera ou de correto/errado.                  |
| Ranking dos jogadores                                          |                                                                                                                      |                                                                       |
| Encerramento da rodada                                         | Top 10 de todos os jogadores.                                                                        | Posição atual e total de pontos.                      |
| Encerramento do jogo                                           | Contagem regressiva do 10º ao 1º lugar e, depois, o top 10 final.                                    | Classificação final e total de pontos.                |
