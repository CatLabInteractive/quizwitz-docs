# Temas

:::warning
Embora criar o teu próprio tema QuizWitz ofereça a maior flexibilidade, é um processo complexo e demorado. Na maioria dos casos, é muito melhor personalizar o nosso [tema Emerald](011-emerald-theme.md), que foi desenvolvido especificamente para ser fácil de adaptar.
:::

Os temas QuizWitz são criados usando o **Adobe Animate**. Podes descarregar um [modelo de tema](https://themes.quizwitz.com/empty/quizwitz-empty-theme.zip) para usar como ponto de partida. Tem em mente que criar temas para o QuizWitz é um trabalho minucioso e fica melhor nas mãos de designers experientes que conhecem todos os detalhes do Adobe Animate.

Prefere deixar isso com os profissionais? Envia um e-mail para [support@catlab.be](mailto:support@catlab.be) e podemos preparar uma estimativa para transformar o teu design num tema QuizWitz pronto a usar.

:::tip
Having a graphic designer draw the theme and someone else assemble it in Animate is a common arrangement. The [theme design guide](012-theme-design-guide.md) describes what the designer has to deliver for that to work.
:::

## 🧪 Ferramenta de teste de tema

Quando estiveres pronto para testar o teu tema, **compacta o conteúdo da tua pasta de design** ( — não a pasta em si; ao abrires o zip, deves ver os teus ficheiros, não apenas uma única pasta — ) e envia para o nosso [testador de temas](https://themes.quizwitz.com/). Isso dá-te uma pré-visualização ao vivo de como o teu tema vai aparecer no jogo.

Depois de testares, envia-nos o ficheiro zip por e-mail e vamos associá-lo à tua conta para que possas selecionar e usar o teu tema nos teus quizzes.

## 🖥️ Visão geral dos ecrãs

| Etapa                                                          | Ecrã do jogo                                                                                                          | Dispositivo do jogador (tablet/telemóvel)          |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Ecrã de ligação                                                |                                                                                                                       |                                                                       |
| Ecrã de espera                                                 | Logo do quiz. Exibido enquanto o quizmaster está a ler a pergunta.                    | Uma frase incentivando o jogador a ouvir com atenção. |
| Introdução do jogo                                             | Animação antes do jogo.                                                                               | Ecrã de espera.                                       |
| Introdução da ronda                                            | Animação antes de cada ronda.                                                                         | Ecrã de espera.                                       |
| Perguntas                                                      |                                                                                                                       |                                                                       |
| Anexo                                                          | Visualização do anexo em ecrã inteiro ( — antes/depois de perguntas ou rondas — ). | Ecrã de espera.                                       |
| Pergunta: múltipla escolha sem anexo           | Pergunta + 4 opções de múltipla escolha.                                                              | Ecrã de resposta de múltipla escolha.                 |
| Pergunta: múltipla escolha com anexo           | Pergunta + 4 opções de múltipla escolha + um anexo visual.                                            | Ecrã de resposta de múltipla escolha.                 |
| Pergunta: pergunta aberta sem anexo            | Apenas a pergunta.                                                                                    | Entrada de texto e botão de enviar.                   |
| Pergunta: pergunta aberta com anexo            | A pergunta + um anexo visual.                                                                         | Entrada de texto e botão de enviar.                   |
| Atividade: equipas escolhidas                  | O nome de uma atividade.                                                                              | Ecrã de espera ou ecrã de "foste selecionado".        |
| Comentários                                                    |                                                                                                                       |                                                                       |
| Feedback da pergunta: múltipla escolha         | A pergunta, as opções corretas e a distribuição das respostas.                                        | Correto / errado + pontos ganhos.                     |
| Feedback da pergunta: pergunta aberta          | A pergunta, as opções corretas e a % de respostas corretas.                                           | Correto / errado + pontos ganhos.                     |
| Feedback da pergunta: pergunta aberta + anexo  | A pergunta, as opções corretas, a distribuição das respostas e um anexo visual.                       | Correto / errado + pontos ganhos.                     |
| Feedback da pergunta: múltipla escolha + anexo | A pergunta, as opções corretas, a distribuição das respostas e um anexo visual.                       | Correto / errado + pontos ganhos.                     |
| Feedback da atividade                                          | As equipas selecionadas para uma atividade.                                                           | Ecrã de espera ou de correto/errado.                  |
| Classificação dos jogadores                                    |                                                                                                                       |                                                                       |
| Encerramento da ronda                                          | Top 10 de todos os jogadores.                                                                         | Posição atual e total de pontos.                      |
| Encerramento do jogo                                           | Contagem regressiva do 10º ao 1º lugar e, depois, o top 10 final.                                     | Classificação final e total de pontos.                |
