# 🎉 Aloitus

## Tervetuloa QuizWitziin!

**QuizWitz** on sosiaalinen visa-alusta, jossa voit:

- Pelata hauskoja visoja ystävien kanssa tai yksin
- Järjestää ammattimaisia visatapahtumia live-työkaluilla
- Luoda omia visoja, kierroksia, pelilistoja ja paljon muuta

Tulitpa rentoutumaan, juontamaan tai rakentamaan - meiltä löytyy kaikki tarvittava.

Tutustu hetki eri rooleihin ja käytettävissä oleviin työkaluihin. Siihen menee vain minuutti.
