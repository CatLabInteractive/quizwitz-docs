# Rundetyper

Rundetypen påvirker hvordan spillet viser spørsmålene til spillerne - og hvordan spillerne får poeng.  
I quizer kan du endre rundetypen i valgfeltet **Rundetype** øverst på midten av skjermen.

For alle som vil arrangere tradisjonelle pubquizer der spillerne kan endre svarene sine helt til slutten av runden.  
Disse rundetypene simulerer at man «leverer inn svararkene» etter hver runde.
