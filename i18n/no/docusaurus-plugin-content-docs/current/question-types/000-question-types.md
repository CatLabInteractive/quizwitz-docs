# Spørsmålstyper

QuizWitz støtter ulike spørsmålstyper. Hver type har sine egne regler og spillmekanikker.
Vi anbefaler å bruke en blanding av ulike typer for å holde spillet interessant og engasjerende.

Merk at noen rundetyper begrenser hvilke spørsmålstyper du kan bruke.

## Vanlige spørsmålstyper

Dette er de vanligste spørsmålstypene. De er enkle å forstå og spille.

- [Flervalg](001-multiple-choice.md) (standard)
- [Rekkefølgespørsmål](003-order-question.md)
- [Bildekartspørsmål](004-image-map.md)
- [Rutenettspørsmål](008-grid-question.md)

## Åpne spørsmål

Ved åpne spørsmål må spillerne skrive inn svarene sine.

- [Åpent spørsmål](002-open-question.md)
- [Listespørsmål](005-list-question.md)

## Spesialtyper

Disse spørsmålene gjør spillet litt mindre rettferdig, men de bidrar til at det alltid blir en vinner.

- [Utslagsspørsmål](006-tiebreaker-question.md)
- [Beste svar-spørsmål](007-best-answer-question.md)
